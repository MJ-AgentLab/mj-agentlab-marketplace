# 《普通材料包怎么领取》交互教材绘制指南

## 一、确认的教学目标

- 读者：首次参与本次虚构活动的访客。读者知道自己是否已有有效预约、是否完成导览，但不熟悉领取规则。
- 使用任务：说明从初始状态到成功领取所需的判断与操作，并解释核验失败、库存为零、取消和重新开始的结果。
- 理解问题：
  - 怎样才会从“未核验”变为“已核验”？
  - 已核验后为什么仍可能没有取得材料包？
  - 取消与“重新开始”分别会改变或恢复哪些内容？

本指南中的交互均为教学演示，不会进行真实预约、核验、领取、归还或库存操作。【设计判断：适用于整份教材】

## 二、材料范围与证据边界

### 原材料

《活动材料包领取说明，修订 1》，已完整读取 §1–§8。

材料仅适用于：

- 普通材料包领取；
- 当前只有一名访客操作；
- 本次虚构活动规则。【原材料 §1、§8】

材料不覆盖：

- 工作人员试用证；
- 多人并发；
- 预约时效；
- 跨活动规则。【原材料 §1、§8】

“体验通行证”仅允许观察，不能代替有效预约或完成导览。【原材料 §2】

### 教材必须保留的限制

- “已核验”不等于“已领取”。【原材料 §8】
- “已核验”不保证库存充足。【原材料 §8】
- 材料没有说明怎样补充库存，因此教材不得演示或推断补货操作。
- 材料没有给出多人同时领取时的库存处理方式。
- “重新开始”是材料为教学演示规定的恢复方式，不表示现实系统必定有同名控件。【原材料 §7】

## 三、先呈现的完整规则

在首次展示任何操作结果之前，应先给出以下规则总览。条件、操作和结果不要仅靠颜色区分。

| 操作 | 必要当前状态及条件 | 操作后的明确结果 | 其他情况 |
|---|---|---|---|
| 核验 | 当前为“未核验”；有效预约与导览完成两项均满足 | 状态变为“已核验”；库存不变【原材料 §3】 | 缺少任一条件时，保留“未核验”，指出缺少的条件；库存不变【原材料 §3】 |
| 领取 | 当前为“已核验”，且库存大于 0 | 状态变为“已领取”；库存减少 1【原材料 §4】 | 当前为“已核验”但库存为 0：显示“等待补充”，保留“已核验”，库存不变。其他状态不可领取【原材料 §4】 |
| 归还 | 当前为“已领取” | 状态变为“已归还”；库存增加 1【原材料 §5】 | 其他状态不可归还【原材料 §5】 |
| 取消预约 | 尚未领取 | 预约变为无效；状态回到“未核验”；导览完成情况和库存不变【原材料 §6】 | 当前为“已领取”或“已归还”时，取消不可用【原材料 §6】 |
| 重新开始 | 教学演示中的任意进度 | 清除本轮操作，恢复 §1 的全部初始值【原材料 §7】 | 这是演示恢复方式，不代表现实系统提供同名控件【原材料 §7】 |

“尚未领取”在教材主线中仅用于取消规则，不扩写成材料未定义的新状态。【设计判断：避免增加领域状态】

## 四、整体版面与阅读顺序

### 1. 顶部：范围提示

常显以下信息：

- 这是单名访客领取普通材料包的虚构活动演示。【原材料 §1、§8】
- 初始值：库存 2、状态“未核验”、预约无效、导览未完成。【原材料 §1】
- 体验通行证不能替代预约或导览。【原材料 §2】
- 演示不会执行真实业务操作。【设计判断：防止把模拟误作现实操作】

### 2. 中部：主线演示

采用分步推进，使读者看到“准备条件—核验—领取”三个阶段。【设计判断：对应目标任务，非原材料规定的页面步骤】

每一步同时显示：

- 当前预约情况；
- 当前导览情况；
- 当前访客状态；
- 当前库存；
- 本步唯一直接操作；
- 操作依据及结果。

全程保留前述字段，避免只显示最终状态。【设计判断：帮助区分条件、状态和库存】

### 3. 侧区或下方：分支解释

并列保留三个分支入口：

- 条件不全时核验；
- 已核验但库存为 0 时领取；
- 领取前取消预约。

这些入口是教材组织方式，不是原材料中的业务功能。【设计判断：便于比较关键误区】

### 4. 底部：规则回看与自检

规则依据和限制应随时可见或可直接展开。核心条件、例外和来源不能只在答错后出现。【设计判断：减少依赖记忆】

## 五、主线演示：从初始状态到成功领取

同一名虚构访客贯穿主线。【教学构造：仅用于保持情境一致】

### 第一步：查看初始状态

显示：

- 预约：无效；
- 导览：未完成；
- 访客状态：未核验；
- 库存：2。【原材料 §1】

提示读者：当前尚不具备核验成功所需的两项条件；体验通行证也不能替代任何一项。【原材料 §2、§3】

“继续了解条件”属于教学入口，不改变预约、导览、访客状态或库存。【设计判断：该入口只推进教材说明】

### 第二步：形成核验题设

本步把预约设为有效、导览设为已完成，作为成功路径的教学题设。【教学构造：选用材料允许的条件组合，不声称这些变化由材料中的某个操作产生】

必须明确说明：

- 原材料规定核验所需条件，但没有规定访客如何完成预约或导览。
- 因此，本步只是设定后续核验所需的当前事实，不演示真实预约或导览流程。

此时：

- 预约：有效；
- 导览：已完成；
- 状态仍为“未核验”；
- 库存仍为 2。【教学构造：当前题设；“仍未核验”用于强调条件满足不等于核验已经发生】

不要因为两项条件满足就自动把状态改成“已核验”。核验必须作为单独操作发生。【原材料 §3】

### 第三步：操作“核验”

起始事实：

- 当前状态为“未核验”；
- 预约有效；
- 导览已完成；
- 库存为 2。【教学构造：沿用第二步题设】

直接操作：核验。【原材料 §3】

结果：

- 两项条件均满足，状态变为“已核验”；
- 库存仍为 2。【原材料 §3】

反馈应解释：“已核验”只表示核验条件已经满足并完成核验，不等于已经领取，也不保证库存充足。【原材料 §8】

### 第四步：操作“领取”

起始事实：

- 当前状态为“已核验”；
- 库存为 2。【来自第三步结果；原始初始库存见 §1，核验不改变库存见 §3】

直接操作：领取。【原材料 §4】

结果：

- 库存大于 0；
- 状态变为“已领取”；
- 库存从 2 减少为 1。【原材料 §4】

完成提示只可说明：“本次教学情境中，领取操作得到材料规定的已领取结果。”不得扩大为现实业务成功、长期资格或其他活动也可领取。【设计判断：限制结论范围】

### 第五步：可选演示“归还”

这一步不是达成主要教学任务的必经步骤，作为领取后的补充分支呈现。【设计判断】

起始事实：

- 当前状态为“已领取”；
- 库存为 1。【来自第四步结果】

直接操作：归还。【原材料 §5】

结果：

- 状态变为“已归还”；
- 库存从 1 增加为 2。【原材料 §5】

归还后不要继续推断能否再次核验、领取或取消；材料只明确规定此时取消不可用，没有给出其他后续操作规则。【原材料 §6；其余为材料缺口】

## 六、关键分支演示

各分支采用独立题设。进入或重试分支时恢复该分支明确列出的起始事实，不继承其他分支的操作历史。【设计判断：避免混合状态】

### 分支 A：核验条件不完整

提供三种可比较的教学题设：【教学构造】

1. 预约有效，导览未完成；
2. 预约无效，导览已完成；
3. 预约无效，导览未完成。

三种题设均固定：

- 当前状态为“未核验”；
- 库存为 2。【教学构造：库存采用 §1 初始值】

操作均为“核验”。【原材料 §3】

共同结果：

- 由于两项条件没有全部满足，状态保留“未核验”；
- 库存不变；
- 反馈指出实际缺少的条件。【原材料 §3】

反馈分别写明：

- 题设 1：缺少有效预约；
- 题设 2：缺少导览完成；
- 题设 3：同时缺少有效预约和导览完成。【由 §3 的“两项条件均满足才变为已核验”及“指出缺少哪项条件”得出】

不要把条件不足表述成体验通行证可以补足；材料明确禁止这种替代。【原材料 §2】

### 分支 B：已核验但库存为 0

这是独立教学题设，不是从 §1 的单访客初始主线自然演变而来。【教学构造】

起始事实：

- 当前状态为“已核验”；
- 库存为 0。【教学构造：选取 §4 明确覆盖的库存分支】

直接操作：领取。【原材料 §4】

结果：

- 显示“等待补充”；
- 状态保留“已核验”；
- 库存仍为 0。【原材料 §4】

反馈重点：

- 当前状态允许执行领取操作，但库存为 0，因此没有进入“已领取”；
- “等待补充”不是教材可操作的新状态；
- 材料没有说明谁在何时补充库存，也没有说明补充后的自动行为，教材不得补造。【原材料 §4、§8及材料缺口】

### 分支 C：领取前取消预约

起始事实可采用：

- 预约有效；
- 导览已完成；
- 状态为“已核验”；
- 库存为 2。【教学构造：用于演示领取前取消】

直接操作：取消预约。【原材料 §6】

结果：

- 预约变为无效；
- 状态回到“未核验”；
- 导览仍为已完成；
- 库存仍为 2。【原材料 §6】

反馈要突出：取消并不会清除已经完成的导览，也不会改变库存。【原材料 §6】

若当前状态为“已领取”或“已归还”，取消入口显示为不可用，并说明材料依据。【原材料 §6】不可进一步说明无效尝试会怎样改变字段，因为材料没有规定这种尝试后的字段结果。

## 七、恢复、返回与重试

### “重新开始”

触发入口属于教材界面安排。【设计判断】

执行“重新开始”后：

- 清除本轮操作；
- 库存恢复为 2；
- 状态恢复为“未核验”；
- 预约恢复为无效；
- 导览恢复为未完成。【原材料 §7引用§1】

相邻提示：“重新开始”是本说明规定的教学演示恢复方式，不表示现实系统必须提供同名控件。【原材料 §7】

### 返回上一步

“返回上一步”仅用于回看教材内容，不撤销原材料中的业务操作，也不自行更改预约、导览、状态或库存。【设计判断】

如果需要改变当前题设，应明确选择“重新开始”或重新进入某个独立分支，不能借页面返回暗示业务状态已经恢复。【设计判断】

### 分支重试

重试时清除该分支的旧选择和旧反馈，并重新显示该分支的完整起始事实。【设计判断】旧反馈必须标为失效，新的判断只依据当前题设。

## 八、反馈文案原则

每次反馈都应包含：

- 当前状态与相关条件；
- 本次直接操作；
- 命中的规则；
- 状态与库存结果；
- 不能据此推出的结论；
- 原材料段落定位。

推荐采用以下表达方式：

- “两项条件均满足，执行核验后状态变为‘已核验’，库存不变。【§3】”
- “当前已核验，但库存为 0；执行领取后显示‘等待补充’，状态保留‘已核验’，库存不变。【§4】”
- “当前状态不是‘已核验’，因此领取不可用。【§4】”
- “材料没有规定不可用操作发生后各字段怎样变化，因此这里只判断不可用，不补充字段结果。”

避免使用：

- “满足条件就自动完成核验”；
- “已核验就一定能领到”；
- “等待补充后会自动领取”；
- “体验通行证也算预约”；
- “返回页面就撤销领取”；
- “重新开始是现实系统功能”。

这些表述分别违反或超出 §2、§3、§4、§7、§8 的范围。

## 九、教学自检设计

自检只用于当次规则理解，不输出总分、能力等级或“已经掌握”等结论。【设计判断】

### 自检一：成功核验需要什么

题设：

- 当前状态为“未核验”；
- 预约有效；
- 导览未完成；
- 库存为 2。【教学构造】

提问：此时执行核验，状态和库存如何变化？还缺少什么？

可靠判准：

- 状态保留“未核验”；
- 库存不变；
- 缺少“导览完成”。【原材料 §3】

常见误区：把有效预约单独当作充分条件，或把核验条件不足误说成库存变化。

### 自检二：已核验是否等于可以拿到材料包

题设：

- 当前状态为“已核验”；
- 库存为 0。【教学构造，采用 §4 已覆盖分支】

提问：执行领取后会显示什么？状态和库存怎样变化？

可靠判准：

- 显示“等待补充”；
- 保留“已核验”；
- 库存保持 0。【原材料 §4】

常见误区：认为已核验必然变成已领取。【原材料 §8】

### 自检三：取消会清除什么

题设：

- 尚未领取；
- 预约有效；
- 导览已完成；
- 状态为“已核验”；
- 库存为 2。【教学构造】

提问：取消预约后四项信息分别如何？

可靠判准：

- 预约变为无效；
- 状态回到“未核验”；
- 导览仍为已完成；
- 库存仍为 2。【原材料 §6】

常见误区：把取消误解为恢复所有初始值。完整恢复初始值属于“重新开始”，不是取消。【原材料 §6、§7】

### 自检反馈与重试

提交后说明判断理由、对应段落和误区；允许修改答案并重新提交。【设计判断】改答时清除旧反馈，新反馈只对应当前答案。空白、关闭或未提交保持“待答”，不能判作知识错误。

## 十、视觉与可用性要求

以下均为设计判断，制作后仍需实际检查：

- 状态、条件、库存和提示分别使用固定文字标签。
- 颜色只能辅助，不能成为区分允许、不可用和等待补充的唯一方式。
- 当前步骤、当前题设和模拟性质保持可见。
- 条件比较尽量并列展示，避免要求读者记住上一屏内容。
- 重要限制可直接阅读，不仅依赖悬停或动画。
- 焦点顺序应与阅读顺序一致；操作名称和当前状态应能被清楚识别。
- 在窄屏和放大显示下，条件与对应结果不能错位。
- 动态反馈出现后，应让读者知道变化发生在哪里，并可返回题设或重新开始。

这些是拟采用和待检查的要求，不表示教材已经通过键盘操作、缩放、窄屏或全面无障碍验证。

## 十一、交付前核对清单

- 是否始终把有效预约和导览完成列为核验成功的共同必要条件？
- 是否明确体验通行证不能替代其中任何一项？
- 是否把“条件满足”和“已经执行核验”分开？
- 是否把“已核验”和“已领取”分开？
- 每个领取结果是否同时写明当前状态、库存条件、直接操作、状态结果和库存结果？
- 库存为 0 的情境是否标为独立教学题设？
- 是否避免虚构补货方式、预约时效、多人并发或跨活动规则？
- 取消是否保留导览完成情况和库存？
- 已领取或已归还时，取消是否明确为不可用？
- 归还是否只在“已领取”状态开放，并同时呈现状态及库存结果？
- “重新开始”是否恢复 §1 的全部初始值，而不是只恢复库存或状态？
- 是否说明“重新开始”不代表现实系统存在同名控件？
- 每处不可用判断是否避免补造无效尝试后的字段变化？
- 所有新增入口、题设、返回和重试行为是否标为教学构造或设计判断？
- 自检是否只报告当次答案及理由，不推断长期掌握或能力等级？

## 十二、待补与验证边界

材料未提供下列信息，本指南不补造答案：

- 预约与导览如何实际完成；
- 库存怎样补充；
- “已归还”后的再次核验或领取规则；
- 不可用操作被尝试后，各字段是否变化；
- 多人并发、预约时效及跨活动处理方式。

正式制作后可以检查交互往返、反馈失效、文字对应、键盘焦点、缩放和窄屏表现；这些目前均是待验证项目。本文是可供绘制交互教材使用的设计指南，不是已经制作、测试或发布的教材，也不证明学习者理解有所改善。
