# 交互设计

先完整读[指南框架](guide-framework.md)，复用其核对后的源基准和目标。以下步骤用于确认后的演示、反馈和自检编排，不实现或操作教材，不规定固定控件、课时、题量或展示模板。

## 1. 选必要交互并定生命周期

每项交互服务一个确认的理解问题，说明用途/依据、起始信息与当前态、未知和限制、单个操作/触发、变化、结果身份/范围、理由/缺项/定位及改选、重试、回退和恢复。静态文字、条件表或并列说明够用就用，不为互动造动作。

先区分共享连续状态与独立情境。共享态首步用明示初值，以后据最新结果固定单个操作重新匹配；改变条件不是复位。独立情境每次进入/重试恢复明示题设，标构造身份和范围，不继承别题或初次面板。未知依赖只阻相关后续，可回明确题设或有据恢复，不把未知操作默作完成或未发生。

说明进入、继续、改条件、暂停、退出、重试、返回、复位及旧反馈何时失效。各步保当前事实、动作/触发、局部结果、范围和来源，留分支、循环、例外，不强画单线。源要求操作或触发时，满足条件/改参数只更新判断，不表示动作已发生、成功或业务通过。提交、确认与恢复标模拟，不执行现实操作。

模式按问题选择：展开保上下文与关键常显；比较优先并列、多项同显，不靠记忆；切换标当前范围与返回。关联高亮只用有据对应且可取消；筛选说明条件、隐藏范围与清除，不藏关键例外。分步保全局、位置、触发、往返/重置，无据不造步骤。模拟依源完整性探索输入，不当现实操作或因果验证；自检用于解释与边界，不评能力。

视觉有等价文字，名称、状态和反馈清楚，必要信息不只靠颜色、悬停或动画。键盘、焦点、缩放、窄屏与往返列设计和待检查，不称已经验证操作或访问合规。

## 2. 从本例输入逐项计算，不重写源规则

每个例子、表行和题目都引用适用的完整源基准，并执行以下核算；这是内部方法，不是必须显示的表格。

1. 读取本例当前态、实际输入、变量/域、触发、假设和范围，分已知、明确否定与未知。原变量与派生真假分开；只用该例数据，不复制邻行答案。
2. 固定单个直接操作和本题结果维度，遍查所有相关许可、禁止、排他、恢复与例外。宽规则可覆盖未专名列出的状态/输入；不套别操作条件、不代换近名状态，不从一态结果推出其他态全禁或保持。先改态的路径逐步另判。
3. 先判操作许可，再判全部结果条件和各字段。允许执行不保证目标结果，非目标分支不改成不可执行；目标结果门槛不追加为执行门槛。明确本句是在说可执行、通过、获得结果还是字段变化，标签、概览和短反馈也不混同这些谓词。
4. 按本例逐条计算实际缺项与全部适用原因，再写解释。已满足项不能说缺少，未知项不能当明确否定；逐项反查题干、答案、理由、误区与恢复对应的实际值和源依据，不用“应该核对”代替核对。
5. 逐字段保源明确的变化、保持、清除和恢复，未述维度才未知。条件被读取/判断不证明它保持。已知操作不可用与非法尝试后的未述字段分开；当前单元前提不满足仍查其他规则，不自动全禁、全保持或全未知。

最后先列本例每项已知判断，再列真正剩余缺口；不能用宽泛“后续/能否”把已有直接许可或禁止重写为未知。缺阈值、域、触发者、结果或优先关系不默认数值、自动动作或唯一结果；冲突无适用优先规则则并列。教学假设明标构造/模型及范围，不充事实、不抹冲突；完整规则保组合、边界和例外，部分规则保已知、缺项只阻相关部分。

只判条件真假、不附操作或字段结果时，不强加业务态：AND 有任一明确否即否，OR 有任一明确是即是，另一未知不撤该结果；其余未知才待定，全已知按源逻辑。未知是缺信息，不是新业务值；条件组合成立不证整体可执行、动作发生或其他字段结果。

输入有效与规则完整分别判断。源有允许域，越界标超本模拟范围；源未定义域不造域或判无效，命中全部前提仍保已知。源可达值不是全域，未设类型、上下界或单位不补。另选示例集合/限制须在起始、选项和反馈就地标设计身份、理由、范围；旁处标签不补本处，不误排源允许情形，不靠惯例裁决。

## 3. 分归源结果与教学设计，再组织反馈

先为每项结果定身份，再编同句、列表或组合触发。源引用只覆盖完整源单元支持的动作、对象与字段；新增状态、默认、输入保留、选择、高亮、提示、反馈清除/失效逐项标本处设计身份、理由和范围。同名操作、共同触发、相同终值或统一引用不替新增项背书；整页教学标签、进入/重试说明或邻近原文也不替本处归属。混合表达不清时，可分句/分段分别说明后再引源，不强制格式。

新增教学入口的触发同样是设计判断；复用有据源动作/结果时独立引源，不合成原规范。源启发只作动机，不是新增行为的规范依据；源未述不能推变化或保持。

源恢复复用完整源单元：保原触发、原操作、全部清除/撤销/恢复动作、对象、字段和现实边界，不能只复述终值，也不能把源的清除对象改成新增界面对象。回退写返回态与保留/清除对象，复位列全，不保证现实系统回最后成功态或有同名控件。若同一触发还清理教学选择/反馈，源恢复与新增设计各自归属，不用一个源引用覆盖整组。

实际明示共同前提、完整源单元及覆盖区域/情境后，可在该范围缩写反馈；未建立本处范围则写足，不能借前例、旁表、初始面板、章节号或未来要求。反馈含本例输入、命中规则/缺口、局部结果、理由/误区、限制、定位及恢复，不只列控件名。

重复按最新态和源条件：仍符合且无明定限次/重复例外，沿用源结果，不增值有效或限一次前提。同值赋值仍有源动作/变化量；额外意义、提示或有效性未知不抹已知结果。按框架在同谓词/范围检查排他，不把一种恢复动作说成唯一同终值入口。

分支互斥或有明确优先；累计原因另列并合并所有适用项。逐对检查宽行、任意/其他/未知行的重叠，不能第一匹配丢已知判断、未知或累计缺项。覆盖难说明可选独立固定情境，明示每题事实、分支、复位与假设，不填造规则或删已知。

## 4. 教学自检与重试

只设计教材自检，不在聊天开测验。每题对应确认问题，明示判准需要的当前态、输入、动作/触发、假设、范围和来源，仅相关字段。共享默认须实际说明覆盖哪些题及如何被题设覆盖，不借题名、面板或别题。源完整且局部假设明确才能给确定判定；前提仍缺则给条件化参考和待补，不冒充事实或造规则。

可靠判准有适用材料和可核对结果，容纳成立的多答案，不为单选造唯一。反馈给局部结论、理由、误区、定位、限制及改答/重试/重做/回看。缺定义、规则、情境、优先关系或开放取舍时，只给有界参考：假设、成立思路、待核验和不能判断，不造标准答案、自动对错或声称未评自由文本已核验。

不预选或推荐正确答案，目标推荐不是答题提示。空/无效答、未提交、沉默、超时或关闭保持待答，不判知识错误。改答清除旧判断或明示失效；新提交按当前答，重做明确选择/反馈清除、题设复位与回材料。题干、判准、理由、误区和重试保持同一实际前提，旁处正确不补本题。

可显示已核对、已提交等局部状态，不给总分、能力等级、绩效或长期掌握结论。一次答对、操作完成、信心、点击意愿或提示后改答只证当次事实，反馈后练习不追写此前已掌握。

## 5. 交付前双向反查

从源查每个必要前提、动作/对象和字段是否完整，再从全文每个许可、否定、未知、排他、数量或输入限制反查同一对象、谓词、维度及实际范围。包括首次摘要、图表每条结果/恢复连接、例子、模拟、自检、附录和作者项，不只检查已显示字段的出处。实际范围内才缩写，表达不清回完整文字，不给残缺连接。

再从各题反馈回查实际输入、答案、缺项、理由、误区和恢复；区分必要性质、纯条件与完整操作，检查源与新增触发/结果的本处分归、共享态/独立题设/重复/返回/旧反馈的一致。其他段落正确不抵消本处错误，编写要求不等于已经建立范围，不按关键词裁决。

完整/缺失规则、可靠/不可靠判准分开；拟检查与已验证分开。示例、拒绝和引用仅自然语言保义定位，不重印 HTML、代码、伪代码、图形语言或制作命令，不写工具配置、文件结构和制作发布步骤。可列新情境解释、遗漏、来源、无效操作、往返查找的待检查项；设计、模拟、自检或静态检查不证明效果、稳定掌握或全面可访问性合规。
