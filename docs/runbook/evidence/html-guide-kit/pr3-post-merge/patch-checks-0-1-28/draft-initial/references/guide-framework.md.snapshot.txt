# 指南框架

负责证据、目标、完整源基准和表达选择；逐例计算见[交互设计](interaction-design.md)。本流程用于内部核对，不强制指南的章节、表格、字段展示或控件格式。

## 1. 读取证据，确定适用材料

分别记录宿主入口正文、实际回包、补读及实际顺序。成功、长度、外层汇总或模型自述不证明全文；截断按现有权限补齐，否则标未读范围，不补写理想读取顺序。逐份直接读单文件/片段，不将多份正文、统计、目录扫描或编码脚本打包读取。明确权限拒绝不绕过。泛化拒绝只证明本次未完成，原因与权限范围未知；只读模式、缓存/工作目录位置、缺正文或别文件成功不证拒因，也不保证换客户端可读。只报告回包明确支持的限制类型、对象、范围和原因。

列材料名称、版本或明确快照、定位、已读范围。文件定位到章/行，网页到实际页面/章，粘贴标本次快照，不造版本或定位。跨会话只用明确快照，不假同步；无教材或明确主题快照则索取，不自定主题。方法参考只在用户明定时作教材。范围拒绝只据入口合同，缺正文则索取。

逐项分清四种身份：

- 原材料：保关键原文、关系、条件、例外、不确定性和范围；陈述或提案不等于已实现、已验证。
- 已核验背景：必要或有时效的判断实际读第一手来源，只列核验命题及范围；可读、记忆和常识不是核验。
- 教学构造：虚构情境、角色、值或假设，就地标身份和适用范围，不冒充记录、规则或领域证据。
- 设计判断：组织、交互、新检查轴和有限推论，标理由与边界，不称源明说或已测效果。

相邻原文不能给新增内容背书。冲突并列保留主张、来源和条件；仅已取得且适用的明确优先规则可用于判断，仍保冲突，不靠术语、版式、常识或推荐裁决。更新区分保留、替换、历史与待定：被替换条款连条件、例外、附注退出当前，不从旧版回填；历史标失效，不参与当前模拟或判准。更新范围不明先澄清，不默认整份替换或任意保留。

材料摘要先保逐项已知，再列实际缺口。缺口只限制相关部分；未确认目标不等于各角色/任务信息皆缺，附加拒绝理由须逐项有据。确认后以下源基准也用于回查首次摘要。

## 2. 给实际不同的目标，等待明确选择

每次新建给 2–3 套 Audience、Task、Understanding Questions。读者写相关情境、责任、前置知识，不推人格、智力或能力；任务是具体判断或说明，理解问题可观察，并标材料支持与缺口。差异来自信息、任务或深度，不仅换职业名。已有目标可作为一套，仍须选择。

说明取舍、推荐及材料/任务理由，目标推荐不是答案提示。选择前只交材料范围、目标和待选，不提前给章节、互动或成品草稿。明确选定已有方案即足够，不要求关键词或第二批准；修改目标须确认采用修改后版本。

默认、推荐、预选、沉默、超时、无关含糊回复或窗口消失不算选定；一般授权、工具默认和不指目标的“直接做”不跳过。歧义只澄清；未答保同一方案，可重述不自换。仅用户修改或材料实质改变才更新再等，用户停即停。不承诺宿主锁定、持续显示或恢复。

## 3. 确认后建立一次完整源基准

先定原意再改写。为每条源规则建立一次完整单元，后续表达从它复用，不在各段另造简版规则。源单元保关键原文或忠实转述、来源定位、适用范围、不确定性：操作材料还保当前态、输入、单个直接操作、全部条件/例外和源明确的动作/对象/字段结果；非操作材料保概念、关系、主张与证据，不制造操作目录。

清除、撤销和恢复也是动作，不能只记终值；未定义对象保原称呼与缺口，不扩成业务日志、永久删除或外部行为。短引或转述紧邻条件、限制和定位；摘要、案例和索引不是原文全部权威。术语、中文对照和值型跨正文/标签/表/自检保持一致，原变量与派生真假分名并给推导。且/或、可能/保证、未说明/没有、可以/必然、本例/所有不互换。

固定所问对象、当前态、单个直接操作和结果维度，匹配全部相关规则，含宽许可、禁止、排他、恢复和例外。未专名列出的状态/输入仍可能被“仅/其余/不得”等完整规则覆盖；一态的结果不默示他态禁止或保持，不套别操作前提，不代换近名状态。

将以下判断分别保存：

- 操作许可：当前能执行、不可执行或未覆盖。
- 分支结果：执行后在什么条件下得到目标或非目标结果。
- 字段结果：源明确变化、保持、清除/恢复，以及未述维度。
- 额外路径：先改变状态再执行的各步另核，未知新增流转不撤现有直接操作判断。

许可不保证目标结果，成功条件不自动成为执行门槛。表达“可执行”“通过”“有效”等时先确定本处谓词；源或本指南已完整定义且实际范围适用才可缩写。必要性质或纯条件判断不强加业务态，也不冒充完整操作结论。

逐项保已知后，仅对真正剩余维度说未知。未知字段、额外意义、提示或重复细节不把整个操作变成未知；非法尝试的许可已知，未述尝试后字段另记。宽泛“后续/能否”须限定具体操作、维度和范围，不能盖过已知允许或禁止。当前规则前提未满足时继续匹配其他有关规则，不自动全禁、全保持或全未知。

初值、赋值/运算、源可达值、允许域和值型分开；可达性质不是全输入域。未述上下界、整数性、单位或有效性保未知，不造域、不禁用已命中全部源前提的输入。教学另选集合或限制须在起始、选项及反馈就地标构造/设计、理由、范围，不改变源覆盖。对象/情境范围不自动限定字段值；某事项不适用不代表其持有者在其他已覆盖事项也不适用，另选读者子集不是新增源资格。

## 4. 从基准选择表达，实际声明复用范围

按确认问题、关系/分支/依赖/冲突/例外的复杂度和篇幅偏好取舍、分组、排序。减少不必要的重复规则和例子，不删核心条件。静态够用就用静态，无固定章数、图、控件或题量；关键结论、条件、例外、限制、定位和比较始终可见，不依赖主动发现。

需要复用时，实际明示本处继承哪组完整源单元、适用于哪些区域和情境；范围内可保义缩写，范围外写足或明确引入。只提章节号、初值、前例、旁表、后置正确内容或“以后可以引用”不建立本处范围。表述不清时选完整文字或源单元，不给残缺结果连接。

关系表达按真实关系选择：分类可用有名清单/表，不暗示步骤、互斥或穷尽；层级可用树，多归属可用表，页面层级不证领域包含。过程保分支、循环与跳过，先后不证因果，条件满足不证动作发生。依赖写清谁需什么，不造运行顺序、不压多对多。因果留条件、范围和依据；相关、相邻、参数变化或演示不证明因果。数值留单位、尺度和来源，不造数、不以面积夸差。颜色、空间、大小、对齐、图标只辅原义；源顺序、阅读顺序和演示顺序分清。

图连接给起终、含义、方向、依据和条件。表达许可、状态转换或字段结果时，保完整前提、直接动作和源结果，或明确继承适用完整单元；资格节点不独自连操作成功或结果态。纯条件、属性比较、必要性质明确所谈维度，不强加源未设前提。

排他先定对象、谓词和局部范围，再查同维度依据；源明说或完整适用枚举才能支持“仅/才/始终/必然”。须考虑有关常规动作、恢复、重置、例外和明标教学设置，只演示一条路径不证排他。执行恢复动作与得到相同终值不同：同值不证同动作、触发、等价或唯一入口。不确定则不作排他，按实际命题审，不按关键词裁决。

## 5. 用同一基准完成交付核对

按[交互设计](interaction-design.md)逐例核算，从源到全文查遗漏，再从每个结论反查源、实际输入与范围。检查包括首次摘要、概览、局部图表、反馈、恢复、自检、附录和作者清单。旁处正确不抵消本处错误；未来编写要求不是已有范围。源无条件结果不加条件，许可短句、推荐反馈和作者项也不能改变谓词。

源与教学设计逐项归属，恢复保原触发、动作、对象、全部字段及现实边界；新增触发、输入保留或反馈清除另作本处设计说明，不能统一引源。详细分归与生命周期按交互设计核对。

按用户单位预算全部可见文字，含标题、标签、提示、附注；正文约80%，全稿同单位复核，超限压重复但保条件、例外和定位，不塞附录或后续消息规避。仅聊天交付可复制指南，含确认目标、范围/限制、必要演示/自检、定位和待补检查，不制作、写入或执行。拟检查与已验证分开；设计不证明效果、稳定掌握或全面可访问性合规。
