# 交互设计

本参考不实现/操作教材。完整读[指南框架](guide-framework.md)，继承证据、源规则、归因和输出边界。目标按框架§3：已有方案明确选定即足够，修改后目标须确认采用，推荐/默认不选定，不要求特定关键词或第二批准。以下补操作/反馈/恢复，非必选控件/课时。

## 1. 交互说明与模式

每项说明：理解用途/依据；起始信息、当前态、未知/限制；明确操作/触发；变化及仍可见条件；局部结果是模拟/参考/有据判断；反馈理由、缺项、定位/边界；改选、重试、回退、复位及旧反馈失效。短段或表格皆可；交互须帮当前问题、收益值得成本，静态文字/条件表/并列说明也可完整交付。

可选模式按用途选择：

- 展开 Disclosure：低频细节，入口有意义、留上下文；比较可多项同显，结论/限制常显。
- 切换 View switching：无需并列的独立视图，标当前、范围、返回；比较优先并列，不靠记忆另一屏。
- 关联高亮 Linked highlighting：已有对应，文字标签/取消/非颜色提示，不造关联。
- 筛选 Filtering：相关子集，显示条件/范围/隐藏内容/清除，不无声滤关键例外。
- 分步 Step-through：有据过程/状态，留全局/当前位置/触发及暂停/前进/回退/重置，无依据不造步骤。
- 条件模拟 Condition simulation：探索源规则在不同输入下的结果，按规则完整性限定，不当真实动作或因果验证。
- 教学自检 Learning check：练习解释规则、关系和边界，按可靠判准分反馈与参考，不自动评能力。

视觉配等价文字，必要信息不只靠颜色/悬停/动画；名称/状态/反馈清楚，考虑键盘/焦点/缩放/窄屏。只提设计及待检查，不称已通过访问/操作验证。

## 2. 演示与恢复

同组明确材料贯穿步骤，避免频繁换情境。每步给当前事实、单个操作/触发、变化、局部结果/限制/来源，留分支/循环/暂停/退出/例外，非强画单线。源需人为触发时，满足条件/改参数只更新可执行判断，非动作已发生/成功/业务通过。提交/确认/恢复标模拟，不外部执行。

操作与恢复遵循框架§5完整规则及覆盖范围，所有区域不自由省前提。恢复非仅初值，小图标局部并指完整恢复；回退说返回态及保留/清除，重置说全部恢复/清除对象，不保证现实系统回到最后成功态或有同名控件。

新增状态/默认/输入保留/选择/高亮/提示/反馈清除或失效，与源结果分列，就地标设计、理由、范围；源未述不推变化/保持。整页构造或进入/重试说明不替具体结果标签；源启发设计非规范依据，标签不抵消后句错归因，恢复/反馈/答案/作者清单同样回查。新增教学入口与源动作分开写：入口触发条件相邻标教学设计，复用的恢复动作、对象、字段及结果独立列源定位；不把二者合成原规范，相同结果不证明相同触发。

## 3. 条件模拟边界

先核对变量/域/当前态/前提/触发/结果/优先/例外/范围/定位，再定可判输入：

- 完整覆盖：必要组合/边界/例外，结果有理由/依据/范围。
- 部分分支：已覆盖可判，其他标未规定及缺项，非全拒。
- 缺阈值/域/触发者/结果：保缺口及影响，不默认数值/自动动作。
- 冲突无适用优先：并列来源，不选方便结果/造唯一规则。
- 教学假设：单列构造/模型及范围，不充原规则/事实或抹源冲突。

规则完整与输入有效分开：源有允许域，越界标超本模拟范围、非正常分支；域未定义不造域/判无效，已命中规则及全部前提仍判已知。可达性质非全域；额外集合/类型/上下界按框架§6在起始、选项、反馈就地标构造/设计及范围，旁处标签不补本处。

按框架§5固定当前态/单个直接操作，匹配全部宽规则、排除、恢复、例外。确定否定仅源必要条件/排他/禁止支持；一态结果不默示他态禁止/保持。别操作前提不套、近名状态不代换，反例不误排源允许态；内部冲突回查、不足待定不靠惯例。先改态路径未知不撤销已知直接结果，操作/路径分判。

纯条件真假不附操作/字段结果可独立判，不强加业务态；附结果须全当前态/操作前提。且有任一明确否即否，或有任一明确是即是，另一未知不撤销；其余未知才待定，全已知按源。未知是缺信息非新业务值，组合成立非整体可执行/已发生，也不定他字段。

## 4. 生命周期与反馈

先定进入、当前态/输入来源、继续、改条件、重试、退出、复位，再写反馈。共享首步初值、以后最新态固定单个操作重匹配，改条件非复位；独立情境每次进入/重试明示恢复必要题设及依据/范围，不靠初次面板或暗示继承前情境。

写反馈先实际明示共同前提及覆盖分支（标题/表首/相邻说明），范围内可缩写；未实际建立本处范围则逐条写足当前态/输入/操作，不借前行/旁表/前例/初始面板。“可执行”等推荐短句也是操作结论，必须满足全部前提；只列资格条件时标条件判断，不升级为操作允许。不把拟写要求或出处章节当成已有范围。再逐操作、逐结果维度匹配全部相关源规则，分别判断已允许、已禁止/不可用或未覆盖；源明定不可用是已知判断，非法尝试后的未述字段才未知，不合为全组待定，也不补保持/变化/清除。最后检查依赖未决态/字段的后续，仅相关部分待定；可返回明确题设或有据恢复继续，不把未知操作默作完成/未发生。当前块前提不满足时查其他源规则，不自动禁止/保持/全未知。

重复按最新态及源条件；仍符合允许条件且无明确限次/重复例外则沿用源结果，不添值有效/限一次前提。同值赋值仍有结果/变化量；额外意义/提示缺口不抹已知操作或状态数值。排他按框架§4须源明示或完整局部枚举含恢复/例外，就地限范围。

分支互斥或明示优先，累计原因另列清单合并全部适用项。逐对查任意/其他/任一未知等宽行，不盖已决定组合、不第一匹配丢已知缺项/未知/累计项，全文边界/自检/恢复一致。覆盖难写清可选独立固定情境，明示题设/分支/每次复位/局部假设，不填造源规则或删已知结果。

示例给当前输入、命中规则/缺口、局部结果、限制、理由/误区、恢复，非仅控件名。条件满足非验证成功/动作完成/真实业务通过，模拟/构造/设计/核验主张分标。

## 5. 教学自检

自检仅指南设计，不在聊天开测验。每题对确认问题列依据、反馈所需态/输入/假设/范围，仅相关字段；共享默认明示覆盖题目及题设覆盖方式，不借题名/面板/前例/别题。可标局部题设假设，源够才限假设判定，不冒充事实/造规则；前提仍缺给条件化参考/待补，不给唯一答案。

可靠判准有适用材料和可核对结果，多答案可成立就容纳、不为单选造唯一；提交给局部判断/理由/误区/定位/限制，允许改答/重试/重做/回看。不可靠如缺定义/规则/情境、冲突或开放取舍，只给有界参考：假设、成立思路、待核验和不能判断；无假标准答案/自动对错，不称未评自由文本已核验。

不预选/推荐正确答案，目标推荐非答题提示；空/无效答、沉默/超时/关闭保持待答，非知识错误。改答使旧判断清除/明确失效，新提交按当前答；重做说清选择/反馈清除、题设复位、回材料。题干/判准/理由/误区/重试同一前提，旁处正确不补本题。

可用已核对、已提交等局部状态，不出总分、能力等级、绩效或长期掌握结论。一次答对、全操作完成、信心、点击意愿或提示后改答，仅支持相应当次事实；反馈后练习不追写此前已掌握。

## 6. 全篇核对

交付前遍历全篇（概览/图示/表/恢复/自检/附录/作者清单）逐项审校：先对每个操作/维度核对当前态、条件、全部源动作/对象/明确字段及定位，分别保留已知判断和未覆盖字段，校正允许/不可/只能/未规定及数量；再对每个新增触发/动作/结果核对相邻的设计身份、理由和范围，与源恢复结果分开归因，不能借同名操作或整页标签混为源规范。对图的每条结果连接另核起始态、直接操作、必要条件及终态/字段；对照实际节点、连线标签和本图明示范围，不能用旁处规则补省略的状态转换前提；仅资格关系不擅自升级为操作结果。依据实际语义和对应关系核对，不按关键词判决；完整共同规则及归因已明确覆盖本处时可保义缩写。最后核对目标/生命周期一致，条件/例外/未知/来源/比较可见，完整/缺失规则和可靠/不可靠判准分清，反馈有理由/误区/恢复；旁处正确不抵消本处错误。

示例/拒绝/引用以自然语言保义定位，不重印 HTML/代码/伪代码/图形语言/制作命令，不写工具/配置/文件结构/制作发布步骤。可拟检查新情境解释、遗漏、来源、无效操作、往返查找；未执行标拟/待检查。设计/模拟/自检/静态审查不证理解改善、稳定掌握或全面可访问性合规。
