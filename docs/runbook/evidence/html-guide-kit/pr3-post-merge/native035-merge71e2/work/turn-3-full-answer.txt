《共享设备借用说明》交互教材绘制指南  
依据：修订1，2026-10-14，本次完整材料快照§1–§4，虚构教学材料。

**确认目标与材料范围**

读者为教学情境中向成员解释结果的设备值守人员，责任是把条件、操作和结果说清楚，前置知识为已读§1–§4。

使用任务：针对核验缺项、等待补充、借用或归还不可用等情况，给出有条款依据的解释。

本指南围绕三个理解问题组织：

- 核验失败应说明哪些缺项？
- 等待补充与资格不足有什么区别？
- 操作被禁止时，哪些结论已有依据，哪些字段结果没有规定？

原材料仅适用于单名已登记成员借用普通设备（原材料§1）。多人并发、登记有效期和跨场地规则未规定（原材料§4），不纳入本指南的判断。

本指南未引入外部背景。下文的情境题设属于教学构造，展示、切换和反馈安排属于设计判断，分别就地标明。

**完整源规则：所有解释的共同依据**

以下规则及适用范围共同覆盖本指南的说明、示例、反馈、恢复、自检和交付核对。各处缩写均在这一范围内使用；教学新增安排另行归因。

初始状态为“未核验”，可用数量为1（原材料§1）。登记有效和培训完成必须同时满足；旁听证只能观察，不能替代这两项条件（原材料§2）。材料未给出登记有效、培训完成或旁听证持有情况的初始值，不预设这些值。

| 必要当前态及条件 | 单个直接操作 | 原材料明确规定的动作与结果 |
|---|---|---|
| 状态为未核验；登记有效且培训完成 | 核验 | 状态变为已核验；可用数量不变。（原材料§2、§3） |
| 状态为未核验；登记有效、培训完成至少一项不满足 | 核验 | 状态保留未核验；说明缺项；可用数量不变。（原材料§2、§3） |
| 状态为已核验；可用数量大于0 | 借用 | 状态变为已借出；可用数量减1。（原材料§3） |
| 状态为已核验；可用数量为0 | 借用 | 显示等待补充；状态和可用数量不变。（原材料§3） |
| 状态不是已核验 | 借用 | 借用不可用；非法尝试后的状态、数量及提示内容未规定。（原材料§3） |
| 状态为已借出 | 归还 | 状态变为已归还；可用数量加1。原材料未另加数量条件。（原材料§3） |
| 状态不是已借出 | 归还 | 归还不可用；非法尝试后的状态、数量及提示内容未规定。（原材料§3） |
| 演示范围内；材料未另加当前态条件 | 演示重新开始 | 恢复§1的全部初值，即状态恢复未核验、可用数量恢复1；不代表现实系统提供同名操作。（原材料§1、§4） |

原材料未规定其他状态下核验的许可与结果，也未规定已核验且数量小于0时借用的结果。可用数量的完整输入域、整数性和上下界未说明；不把这些未规定事项自行判为无效。

核验、借用和归还对登记有效、培训完成等其他信息是否产生影响，原材料未说明。解释结果时只陈述已经明确的字段，不补写其他字段“变化”或“不变”。

**解释结果时采用的顺序**

采用“当前事实—直接操作—命中规则—明确结果—剩余缺口”的说明顺序（设计判断：帮助值守人员把判断依据与结论对应起来；适用于本指南全部解释）。

每次先固定当前状态及一个直接操作，再读取该操作所需条件：

- 解释核验：需要当前状态，以及登记有效、培训完成的情况。
- 解释借用：需要当前状态；状态为已核验时，还需要可用数量。
- 解释归还：需要当前状态；原材料没有设置额外数量门槛。

以上所需事实依据原材料§2、§3；逐项呈现的顺序属于设计判断。

登记有效和培训完成的真假判断可以单独说明，但不得直接写成“可以借用”。借用结论必须同时落实当前状态、直接操作及相应数量条件（原材料§3、§4）。

**情境解释区：分别展示三类原因**

采用独立情境供读者选择，便于比较不同原因（设计判断）。每个情境都有自己的当前态和输入，不继承其他情境的结果（教学构造与设计判断）。

下列数量0和1是局部题设，未声称穷尽数量输入域。“已核验、数量0”用于解释原材料明确规定的分支，未声称它能由§1初值沿现有操作到达。

| 独立教学题设与被解释的操作 | 展示的解释 |
|---|---|
| 状态未核验；登记无效；培训未完成；数量1；操作为核验。（教学构造） | “本次核验缺少登记有效和培训完成两项条件。核验后仍为未核验，可用数量仍为1。”两项缺项分别列出，不只显示一项。（原材料§2、§3；分列方式为设计判断） |
| 状态未核验；登记有效；培训完成；数量1；操作为核验。（教学构造） | “两项资格条件同时满足。本次核验使状态变为已核验，可用数量仍为1。”这一结果不表示借用已经发生。（原材料§2–§4） |
| 状态已核验；数量0；操作为借用。（教学构造） | “本次借用进入等待补充分支，因为当前可用数量为0。状态仍为已核验，数量仍为0。”不把这一原因写成资格不足。（原材料§3） |
| 状态已归还；数量1；操作为借用。（教学构造） | “当前状态不是已核验，因此借用不可用。材料没有规定此次非法尝试后的状态、数量或提示内容。”数量大于0不能替代状态条件。（原材料§3） |
| 状态已借出；数量0；操作为归还。（教学构造） | “当前状态为已借出，归还使状态变为已归还，可用数量由0增加为1。”不为归还增设库存门槛。（原材料§3） |

每条解释旁边常显当前状态、单个操作、相关输入及条款定位（设计判断：读者无需凭记忆补齐前提）。“资格缺项”“等待补充”“状态不允许”使用文字区分，颜色只作辅助（设计判断）。

旁听证的说明应常显：“旁听证只能观察，不能替代登记有效和培训完成”（原材料§2）。不要据此推断旁听证持有者在其他已覆盖事项中一律不适用；具体操作仍按当前态及相应规则判断。

**操作、反馈与恢复的生命周期**

情境区的“选择情境”和“查看解释”都是教学展示入口（设计判断：供读者查找对应理由，范围仅限教材）。它们展示上述参考结果，不执行真实核验、借用或归还，也不把题设自动改成操作后的状态。

每次进入或重新查看某个情境，恢复该情境明确列出的教学题设（教学构造与设计判断：保证解释与当前题设一致）。这属于情境展示安排，不冒充原材料§4的演示重新开始。

切换情境时，旧解释不再适用于新题设；清除旧解释并显示“当前情境尚未查看解释”（设计判断：避免把旧反馈误用到新情境）。新增提示、选择和反馈的清除均属于界面安排，不归因于原材料。

如果设置“演示重新开始”入口，须分开说明：

- **入口触发：**读者主动选择该教学入口（设计判断：便于重新查看演示起点；仅限教材）。
- **原材料规定的恢复动作：**演示重新开始恢复§1全部初值，状态恢复未核验、可用数量恢复1（原材料§1、§4）。
- **新增展示恢复：**清除当前情境选择及教学反馈（设计判断：避免旧解释与恢复后的展示混用；仅限界面）。
- **现实边界：**该演示恢复不代表现实系统提供同名操作（原材料§4）。

不把登记有效、培训完成或旁听证持有情况写成原材料规定的恢复项，因为原材料未定义这些信息的初值。

**拟设置的教学自检**

自检用于练习解释条款，以下是指南设计，不在聊天中向读者发起测验。每题使用独立教学题设，不继承情境区或其他题目的状态（设计判断）。

| 独立题设与说明任务 | 判准、理由及常见误区 |
|---|---|
| 未核验；登记无效；培训未完成；数量1；直接操作为核验。要求说明缺项与结果。（教学构造） | 应说明两项缺项；状态保留未核验，数量仍为1。（原材料§2、§3）常见误区是只列一项，或用旁听证替代条件。 |
| 已核验；数量0；直接操作为借用。要求解释等待补充的原因及字段结果。（教学构造） | 应指出数量为0；显示等待补充；状态和数量不变。（原材料§3）常见误区是把已核验等同于已借出，或把等待补充解释为资格不足。 |
| 未核验；数量1；直接操作为归还。要求区分确定结论和未规定事项。（教学构造） | 归还不可用，因为仅已借出可以归还；非法尝试后的字段结果未规定。（原材料§3）常见误区是把整个判断都说成未知，或自行补写数量增加、不变。 |
| 已归还；数量1；直接操作为演示重新开始。要求解释恢复结果和现实边界。（教学构造） | 状态恢复未核验、数量恢复1；不能据此宣称现实系统提供同名操作。（原材料§1、§4）常见误区是只说清除提示，或附加未规定的资格恢复项。 |

以上题设支持逐项核对，不要求与参考措辞完全一致（设计判断）。反馈须分别指出已说明项、遗漏项、条款理由和适用边界。

改答时旧判断失效；重新提交后依据当前答案核对。重做时清除回答和反馈，并恢复该题完整教学题设（均为设计判断：保证反馈对应当前回答）。空答保持待答，不当作知识错误。

自检不设置能力等级、绩效评价或长期掌握结论；一次答对及提示后改答只反映当次回答情况。

**交付核对与待补事项**

本指南已对照原材料§1–§4进行文字核对：资格条件、操作前提、已知禁止、明确字段结果、源恢复动作与教学新增安排均分别说明。

键盘操作、焦点顺序、窄屏展示、缩放和非颜色提示属于拟检查项，尚未实际验证。关键条件、例外、来源及比较理由应保持可见（设计判断）。

若后续要扩展解释范围，需要补充多人并发、登记有效期、跨场地规则、补充设备的操作规则，以及非法尝试后的字段处理。现有材料足以支持本指南已列出的局部判断，这些缺口不撤销已有结论。

本次交付为可复制的指南文本；未制作或发布教材，也未验证理解改善、稳定掌握或全面可访问性合规。
