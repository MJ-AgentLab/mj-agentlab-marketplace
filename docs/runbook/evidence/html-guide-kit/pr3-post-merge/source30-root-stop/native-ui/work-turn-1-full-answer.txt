已依次完整读取指定安装入口的 SKILL.md、guide-framework.md、interaction-design.md，以及你提供的《共享设备借用说明》修订1（2026-10-14）完整对话快照，覆盖 §1–§4。

本次教材依据限定为这份虚构教学材料，适用单名已登记成员借用普通设备；不扩展多人并发、登记有效期或跨场地规则。以下仅提出目标，等待你选择。

1. **方案 A：首次借用者——判断自己现在能做什么（推荐）**
   - **读者：** 首次接触说明的已登记成员，尚不熟悉资格与状态的区别。
   - **使用任务：** 根据登记、培训、当前状态和可用数量，判断当前操作是否允许，以及会得到什么结果。
   - **理解问题：** 两项资格为什么缺一不可，旁听证能否替代？符合资格、已核验与已借出有什么区别？为什么已核验仍不保证借到设备？
   - **取舍：** 优先解决实际判断中的关键混淆，较少深入连续操作与规则边界。上述问题均有 §1–§3 支持。

2. **方案 B：流程练习者——追踪每次操作后的状态与数量**
   - **读者：** 已了解基本术语，希望准确说明借用过程的成员。
   - **使用任务：** 从明确起点逐次判断核验、借用、归还和演示重新开始的结果。
   - **理解问题：** 核验未通过时应说明哪些缺项，数量是否变化？借用时数量为零会怎样？归还需要什么状态？演示重新开始恢复哪些初值？
   - **取舍：** 着重操作前后的一致性，需要同时关注状态、数量与触发动作，内容比 A 更细。依据为 §1–§4。

3. **方案 C：培训讲解者——解释规则依据与适用边界**
   - **读者：** 熟悉说明内容、需要向他人回答疑问的讲解者。
   - **使用任务：** 用条款依据解释常见误读，区分材料已有结论与材料未规定的事项。
   - **理解问题：** 如何解释旁听证的作用？为什么不能把已核验说成已借出？为什么演示重新开始不能证明现实系统有同名操作？遇到多人或跨场地问题，材料能支持到哪里？
   - **取舍：** 更重视解释的准确性与边界，较少练习连续操作。前述解释有 §2–§4 支持；多人并发、登记有效期和跨场地规则属于 §4 明示未规定的范围。

**推荐 A**：这份材料的核心难点是区分资格、核验状态与借用结果，A 最直接对应这些理解问题。

请选择 **A、B 或 C**；也可以明确提出要调整的读者或任务。
