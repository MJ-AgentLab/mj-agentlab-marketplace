# 指南框架

负责证据、目标、完整源基准和表达；逐例计算见[交互设计](interaction-design.md)。这是内部流程，不强制展示章节、表格、字段或控件。

## 1. 读取证据，确定适用材料

分别记录入口正文、实际回包、补读及顺序。成功、长度、汇总或自述不证全文；截断按权限补齐，否则标未读范围，不补理想顺序。逐份直读单文件/片段正文，不打包多份正文、统计、扫描或编码脚本。

每次报告拒因前，先核回包实际明示的限制类型、对象、范围和原因。泛化拒绝只证明本次未完成及拒绝事实，未述原因/权限范围仍未知；读取形式、只读模式、目录身份/位置、缺正文或后续成功，不证明先前拒因，也不保证换客户端可读。不作路径权限的因果排查。明确权限拒绝不绕过；泛化拒绝且无具体禁止时，允许在原 Read 授权内继续逐份直读，但它只提供当次读取结果，不验证先前拒因。随后按实际读取顺序核全文，不将后续成功补写成最初成功。

列名称、版本/明确快照、定位和已读范围。文件到章/行、网页到实际页/章、粘贴标本次快照，不造版本/定位。跨会话只用明确快照、不假同步；无教材/主题快照则索取，不自定，方法参考仅用户明定才作教材。范围拒绝只据合同，缺正文索取。

逐项分清四种身份：

- 原材料：保原文、关系、条件、例外、不确定性和范围；陈述/提案不证实现或验证。
- 已核验背景：必要或有时效的判断实际读第一手来源，列核验命题/范围；可读、记忆、常识不证核验。
- 教学构造：虚构情境、角色、值或假设，就地标身份/范围，不冒充记录、规则或领域证据。
- 设计判断：组织、交互、检查轴和有限推论，标理由/边界，不称源明说或已测效果。

相邻原文不为新增内容背书。冲突并列主张、来源、条件；仅已取得且适用的明确优先规则支持判断，仍保冲突，不靠术语、版式、常识或推荐裁决。更新分保留、替换、历史、待定；替换连条件/例外/附注退出当前，不从旧版回填；历史标失效、不参与当前模拟/判准。更新范围不明先澄清，不默认整份替换或任意保留。

摘要先保已知再列缺口，缺口只限相关部分；目标未确认不证各角色/任务皆缺，附加拒因须有据。确认后以源基准回查首次摘要。

## 2. 给实际不同的目标，等待明确选择

每次新建给 2–3 套 Audience、Task、Understanding Questions。读者写情境、责任、前知，不推人格/智力/能力；任务是具体判断/说明，问题可观察并标材料支持/缺口；候选疑问句的预设事实也须核源，尤其区分操作许可与成功结果，不能把相矛盾或未知的前提嵌成已知。差异来自信息、任务、深度，不仅换职业名；已有目标可作一套，仍须选择。

说明取舍、推荐及材料/任务理由，目标推荐不是答案提示。选择前只交范围、目标、待选，不给章节/互动/成品草稿。明确选定已有方案即足够，无关键词或第二批准；修改目标须确认采用修改后版本。

默认、推荐、预选、沉默、超时、无关/含糊回复、窗口消失无效；一般授权、工具默认或不指目标的“直接做”不跳过。歧义只澄清，未答保同一方案、可重述不自换；仅用户修改或材料实变才更新再等。用户停即停，不承诺宿主锁定、持续显示或恢复。

## 3. 确认后建立一次完整源基准

先定原意：每条源规则一次完整单元，后续复用，不另造简版。保原文/忠实转述、定位、范围、不确定性；操作材料保当前态、输入、单个直接操作、全部条件/例外、源明确动作/对象/字段结果；非操作材料保概念、关系、主张、证据，不制造操作目录。

同一源单元先保全部并列动作、对象和非字段效果，再记字段终值；清除、撤销、恢复等动作不因终值相同而省略。可按目标裁减不需要的单元，但实际呈现某操作/恢复单元时保其全部源动作；只说明字段或必要性质时明示维度，不当完整操作。未定义对象保原称呼/缺口，不扩业务日志、永久删除或外部行为。短引/转述紧邻条件、限制、定位，摘要/案例/索引不替原文权威。术语、中文对照、值型跨正文/标签/表/自检一致，原变量与派生真假分名、给推导。且/或、可能/保证、未说明/没有、可以/必然、本例/所有不互换。

固定所问对象、当前态、单个直接操作、结果维度，匹配全部相关宽许可、禁止、排他、恢复和例外。未专名状态/输入仍可能被“仅/其余/不得”等覆盖；不从一态推他态禁止/保持，不套别操作前提、不代换近名状态。

将以下判断分别保存：

- 操作许可：当前能执行、不可执行或未覆盖。
- 分支结果：执行后在什么条件下得到目标或非目标结果。
- 字段结果：源明确变化、保持、清除/恢复，以及未述维度。
- 额外路径：先改变状态再执行的各步另核，未知新增流转不撤现有直接操作判断。

许可不保证目标结果，成功条件不自动变执行门槛。先定“可执行/通过/有效”等本处谓词；完整定义且实际范围适用才缩写。必要性质/纯条件不强加业务态，也不冒充完整操作。

拟列缺口时，先确认源规则的实际对象/范围，再固定当前操作并代入全部实际前提。宽许可命中时保当前许可及明确结果；源未设次数、字段原值或额外历史要求时，不能因这些事项未再次单述而收窄为未知。只有真正剩余维度才未知：未知字段、额外意义、提示/重复细节不撤已知，非法尝试许可与未述后果分记。宽“后续/能否”仍限具体操作、维度、范围。当前单元未命中须匹配其他有关规则，不自动全禁、全保持或全未知；范围外或实际必需前提仍未知时，照原方法保未知，不默认可操作。不为谨慎自增前提或无依据缺口。

先分源条件规则、源初值与本组/本例实际输入。交付中先明示本组判定必需的共同题设、实际覆盖哪些情境和局部覆写方式，再写各例结果；若要把源初值作为共同题设，须实际声明这层赋值，引用源段或“每题明确”的要求不等于已给值。独立例子另给所需输入，不能只列相较别例的变化值便推结果。共同已赋输入可按明示范围复用，无需每例重复无关字段/规则。仍缺必需值时就地明标教学构造补足，或只把依赖结果保无法确定，不从别例擅选，不收紧已知宽许可或不依赖缺项的结论。源给完整条件判准时，按实际且/或关系逐结论求值：且中任一明确假已决定该条件结论为假，或中任一明确真已决定为真，另一项未知不撤结果；其余情况按剩余依赖判断，只有仍需未给信息才保未知。纯必要条件不作充分判准，条件真假不推出未述操作或字段，源范围与适用前提仍须成立。初值、赋值/运算、源可达值、允许域、值型仍分开，可达不证全域。未述上下界、整数性、单位、有效性保未知，不造域、不禁已命中全部前提的输入。教学另选集合/限制，在起始、选项、反馈就地标构造/设计、理由、范围，不改源覆盖。对象/情境范围不限字段值；事项不适用不证持有者其他已覆盖事项不适用，读者子集不新增源资格。

## 4. 从基准选择表达，实际声明复用范围

按确认问题、关系/分支/依赖/冲突/例外复杂度及篇幅偏好取舍排序，减重复规则/例子，保核心条件。静态够用就用，无固定章数、图、控件、题量；关键结论、条件、例外、限制、定位和比较常显，不靠主动发现。

实际明示本处继承哪组完整源单元、适用区域/情境，范围内保义缩写、外部写足或引入。章节号、初值、前例、旁表、后置正确内容或“以后可以引用”不建立范围。说不清回完整文字/源单元，不给残缺连接。

按真实关系表达：分类清单/表不暗示步骤、互斥、穷尽；层级树、多归属表，页面层级不证领域包含。过程保分支/循环/跳过，先后不证因果，条件满足不证动作。依赖写谁需什么，不造顺序、不压多对多。因果保条件/范围/依据，相关、相邻、参数变动、演示不证因果。数值保单位/尺度/来源，不造数、不以面积夸差。颜色、空间、大小、对齐、图标只辅原义，源/阅读/演示顺序分清。

图连接保起终、含义、方向、依据、条件；许可/转换/字段结果保完整前提、直接动作、源结果，或实际继承适用单元，资格不独连成功/结果态。纯条件/属性/必要性质明维度，不强加源未设前提。

排他先定对象、谓词、局部范围，再查同维度依据；源明说/完整适用枚举才支持“仅/才/始终/必然”，并查常规动作、恢复、重置、例外、明标教学设置。一条路径不证排他；同终值不证同恢复动作、触发、等价或唯一入口。不确定不作排他，按实际命题、不按关键词审。

## 5. 用同一基准完成交付核对

依交互设计逐例核算；源到全文查遗漏，每个结论反查源、输入、范围，含首次摘要、概览、图表、反馈、恢复、自检、附录、作者项。旁处正确不补本处，拟写要求不是已有范围。反查每个泛未知反馈的实际依赖，含另设未知输入的教学说明：不能因任一输入未知就把整组判定改为无法确定；已知项已决定的结论须保留，缺项只阻仍依赖它的部分。无条件结果不加条件；许可短句、推荐反馈、作者项不改谓词。

逐处核源与设计归属：先从源到完整基准查全部并列动作、对象、非字段效果和字段终值；实际呈现完整恢复/操作单元时，再按本处逐项核归源内容是否齐全，或明示复用该已核完整单元及适用范围。源已明确的非字段动作仍归源，不能在本处把源结果排他地缩成终值，或把非字段效果一概归设计；旁处正确不补本处错误归属。仅说明某维度时明示范围，不当全部源结果。恢复保原触发、全部动作/对象/字段及现实边界，新增触发、输入保留、反馈清除另标本处设计、理由和范围；不整组引源，详交互设计。

按用户单位预算全部可见文字，含标题/标签/提示/附注，正文约80%、全稿复核；超限压重复保条件/例外/定位，不用附录/后续消息规避。仅聊天交付目标、范围/限制、必要演示/自检、定位、待补，不制作/写入/执行。拟检查不当已验证，设计不证效果、稳定掌握或全面可访问合规。
