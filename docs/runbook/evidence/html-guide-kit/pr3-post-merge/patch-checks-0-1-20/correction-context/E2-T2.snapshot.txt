## 交互教材绘制指南

**确认目标**  
读者为负责现场说明领取规则的工作人员，已知材料中的状态名称。任务是依据单人当前状态，判断材料是否足以确认其具备领取资格，并区分资格、观察权限与实际领取。

**常显规则**  
原材料§2：领取一个普通材料包，必须同时满足“预约有效”与“导览完成”，缺一不可。体验通行证仅允许观察，不能替代预约或导览。  
原材料§8：“已核验”不等于“已领取”，也不保证库存充足；多人并发、预约时效和跨活动规则均未覆盖。以上规则适用于全文的图示、示例、模拟、反馈和自检。

**绘制安排**  
先用并列条件图呈现“预约有效”与“导览完成”共同指向“具备领取资格”；“体验通行证”单列为观察权限，不连接为替代条件。图形关系仅表达§2规则，不表示已经领取或库存可用。

设置单人条件模拟（教学构造）：起始面板分别显示预约、导览、体验通行证和已核验状态。读者每次只改变一个条件；系统按§2重新判断资格。两项必要条件均满足时显示“材料支持具备领取资格”，否则显示缺少的条件。体验通行证变化不改变资格判断。该模拟不执行真实预约、导览或领取。

“重置题设”是设计判断：恢复本次教学示例的初始选择，并清除旧反馈；不代表现实状态被撤销。

**教学自检设计**  
给出三类单人题设：条件齐全、缺少一项、仅有体验通行证。反馈须列命中规则、判断理由与§2定位。另设边界题：“已核验能否证明已领取或库存充足？”依据§8，两项均不能证明。涉及多人、时效或跨活动时，只反馈“材料未覆盖”，不给推测答案。允许改答；新提交后旧反馈失效。

**交付前待检查**  
逐项核对必要条件未被拆成任选其一，观察权限未被画成替代关系，资格未被表述为已领取；确认未知事项始终标为未覆盖。以上为绘制与待检查方案，不表示教材已经制作、测试或验证学习效果。
