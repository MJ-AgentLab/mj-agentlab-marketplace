 # 交互设计
 
+读取失败先区分实际尝试的动作、工具明确返回的事实、仍未知的原因或权限范围。泛化拒绝时可表述“本次读取命令未完成，原因与允许读取范围未确认”；这不是路径或沙箱诊断。仅当实际回包明确说明限制对象、范围及原因时，才在对应范围陈述；不从缓存位置、工作目录、读不到正文或其他文件读取成功，推出路径禁止、沙箱拦截或文件不可读。不要将猜测写成原因、已知范围或事实，亦不承诺改用其他客户端即可读取。
+
+在可用且已授权的只读入口内，可以逐文件或分小片段读取，分别保留每次实际接收范围；不能绕过已经明确的权限限制。无法补读时如实标尚未读取，可索取缺失内容；范围拒绝依据已知合同即可，不必附加未证文件环境解释。
+
 本参考用于描述教学交互，不实现或操作教材。只在交互帮助已确认理解问题时采用；静态文字、条件表和并列说明可以成为完整教材内容。
 
 阅读报告以实际接收正文为据，区分宿主加载的入口正文、工具返回的已读片段、以及同一读取过程后来实际接收的完整补读；命令成功、文件长度、外层汇总输出或模型自述不能证明模型收到了全文。截断未补齐时保留已读范围和限制，不称全文。工具报错只说明已观察到的失败命令或内容范围；通用策略拒绝不证明其原因为文件在工作区外、缓存位置或路径禁令，也不证明所有形式的读取均不可用。原因未证实就保持未知，不以推测理由要求用户复制文件。确有必要且权限允许时可简化为逐文件只读或分段读取；不能越权、承诺必读成功，或把未尝试的读取说成已被禁止。范围拒绝只报告实际据以判断的入口/材料，不虚构参考全文已读。

 ## 选择模式
 
+完整源结果指原材料明确规定的全部动作、对象与字段结果，不是为每个出现的字段补齐变化或不变。只有源明确支持保持，才把保持列入源结果；没有写某字段如何变化，不等于源规定该字段不变。先区分操作条件、源明定结果和未说明字段；条件被读取、展示或用于判断，不自动成为该操作保持的源结果。
+
+教学界面可以另定输入值在一次演示中保留，须在相应交互的此项就地标为设计判断及适用范围，并与源结果分列；整页教学构造、情境进入规则或重试恢复说明不足以标注具体操作结果。引用源段落的结果表、过程反馈、演示说明、自检答案和核对项同样回查。未说明的源结果只保留缺口，不编造变化或保持，不遮掉其他已有结果。
+
 - **展开 Disclosure**：用于低频细节或补充理由。入口有意义，展开后保留上下文；需要比较时允许多项同时可见。结论、重要条件及限制常显。
 - **切换 View switching**：用于当前无需并列的独立视图。明确当前视图、变化范围和返回方式。并列比较任务优先同时呈现，避免要求记住另一屏。
 - **关联高亮 Linked highlighting**：核对原文与表格或图示中已有对应关系。提供文字关系标签、取消选择和非颜色提示，不用高亮制造原材料没有的关联。
