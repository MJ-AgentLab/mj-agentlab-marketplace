# 交互设计

已知会话采用只读模式、技能只有 Read 能力或工程工具的权限设置，只能报告为已知模式事实，不能作为某次读取失败的原因证据。若回包仅说拒绝或策略拦截，就只报告该次命令未完成、工具给出的拒绝事实以及具体原因和权限范围未知；不把策略自行命名为只读、沙箱、路径、安全或其他类型。另一次读取成功只证明另一次成功，不补证前次原因。只有这次实际返回明确说明限制类型、对象、范围或原因，才陈述它明确支持的部分；已知模式与这次拒绝因果分开。

读取失败先区分实际尝试的动作、工具明确返回的事实、仍未知的原因或权限范围。泛化拒绝时可表述“本次读取命令未完成，原因与允许读取范围未确认”；这不是路径或沙箱诊断。仅当实际回包明确说明限制对象、范围及原因时，才在对应范围陈述；不从缓存位置、工作目录、读不到正文或其他文件读取成功，推出路径禁止、沙箱拦截或文件不可读。不要将猜测写成原因、已知范围或事实，亦不承诺改用其他客户端即可读取。

在可用且已授权的只读入口内，可以逐文件或分小片段读取，分别保留每次实际接收范围；不能绕过已经明确的权限限制。无法补读时如实标尚未读取，可索取缺失内容；范围拒绝依据已知合同即可，不必附加未证文件环境解释。

本参考用于描述教学交互，不实现或操作教材。只在交互帮助已确认理解问题时采用；静态文字、条件表和并列说明可以成为完整教材内容。

阅读报告以实际接收正文为据，区分宿主加载的入口正文、工具返回的已读片段、以及同一读取过程后来实际接收的完整补读；命令成功、文件长度、外层汇总输出或模型自述不能证明模型收到了全文。截断未补齐时保留已读范围和限制，不称全文。工具报错只说明已观察到的失败命令或内容范围；通用策略拒绝不证明其原因为文件在工作区外、缓存位置或路径禁令，也不证明所有形式的读取均不可用。原因未证实就保持未知，不以推测理由要求用户复制文件。确有必要且权限允许时可简化为逐文件只读或分段读取；不能越权、承诺必读成功，或把未尝试的读取说成已被禁止。范围拒绝只报告实际据以判断的入口/材料，不虚构参考全文已读。

## 每项交互的说明

对需要的交互写清以下内容，可以用短段落或表格，不要求固定格式：

| 内容 | 需要回答的问题 |
| --- | --- |
| 理解用途与依据 | 读者通过操作要核对哪个问题？规则或关系来自哪里？ |
| 起始状态 | 默认看到什么？有哪些已知条件、未知、限制和当前状态？ |
| 操作 | 读者明确选择、调整、前进、回退或提交什么？操作是否必要？ |
| 变化 | 哪部分内容或状态改变？哪些条件、限制或上下文继续可见？ |
| 结果 | 显示了什么？这是模拟结果、参考思路还是有依据的判断？ |
| 反馈 | 为什么发生变化、为何成立或不成立？缺了什么？依据在哪里？ |
| 恢复 | 如何撤销、改选、重试、回退或恢复初始状态？旧反馈何时失效？ |

必要信息不只靠颜色、悬停或动画表达。重要视觉配等价文字说明；操作有清楚名称、状态和文字反馈，考虑键盘、焦点、缩放与窄屏阅读。只描述这些设计要求及待检查范围，不宣称已经完成访问或操作验证。

## 选择模式

完整源结果指原材料明确规定的全部动作、对象与字段结果，不是为每个出现的字段补齐变化或不变。只有源明确支持保持，才把保持列入源结果；没有写某字段如何变化，不等于源规定该字段不变。先区分操作条件、源明定结果和未说明字段；条件被读取、展示或用于判断，不自动成为该操作保持的源结果。

教学界面可以另定输入值在一次演示中保留，须在相应交互的此项就地标为设计判断及适用范围，并与源结果分列；整页教学构造、情境进入规则或重试恢复说明不足以标注具体操作结果。引用源段落的结果表、过程反馈、演示说明、自检答案和核对项同样回查。未说明的源结果只保留缺口，不编造变化或保持，不遮掉其他已有结果。

- **展开 Disclosure**：用于低频细节或补充理由。入口有意义，展开后保留上下文；需要比较时允许多项同时可见。结论、重要条件及限制常显。
- **切换 View switching**：用于当前无需并列的独立视图。明确当前视图、变化范围和返回方式。并列比较任务优先同时呈现，避免要求记住另一屏。
- **关联高亮 Linked highlighting**：核对原文与表格或图示中已有对应关系。提供文字关系标签、取消选择和非颜色提示，不用高亮制造原材料没有的关联。
- **筛选 Filtering**：在较多条目中寻找相关子集。显示当前条件、结果范围、被隐藏的内容和清除方式；关键例外不被无声过滤。
- **分步 Step-through**：观察有依据的过程、分支或状态变化。保留全局概览、当前位置和触发条件，允许暂停、前进、回退和重置；没有过程依据时不编造步骤。
- **条件模拟 Condition simulation**：让读者探索已给定规则在不同输入下的结果。按下面的完整性门槛确定可判定范围，不把模拟当真实操作或因果验证。
- **教学自检 Learning check**：让读者练习解释规则、关系和边界。按可靠判准门槛区分明确反馈与开放参考，不自动评价能力。

以上是可选模式，不是控件清单或必须覆盖的课时。一个操作说不出具体理解收益，或其成本超过收益时，保留简单静态形式。

交互示例和反馈只用文字描述。即使来源或用户请求含 HTML、程序代码、伪代码或制作命令，也不以引用、代码围栏、示例或附录重印；必要语义用自然语言表达并保留定位。范围拒绝同样遵守这条边界。

材料有操作规则时，编排前先整理完整源规则单元：必要当前状态与输入、单个直接操作、全部明确字段结果、全部明确动作及其对象、条件、例外、局部范围和来源定位。清除、恢复、撤销等源动作与字段结果并列保留，不能只整理最终值而漏掉其他结果；保留关键原文及限定。源对象未定义时保留原称呼和缺口，不扩写成业务日志、审计记录、永久删除或外部系统行为。操作判断先固定本次当前状态与单个直接操作，分别匹配所有相关源规则，明确已允许、已禁止和未覆盖；源已有宽规则或排除条款仍适用，不因没有单列特例、重复或结果同值而变未知。先经过其他操作改变状态后的路径另行判断；路径未知不撤销固定当前状态下已知的直接操作结果。不把不同操作用“甲或乙”“再次操作”等合并成统一允许、禁止或未知。


有操作规则的指南，在首个改写的操作结果之前，向读者呈现完整源规则与共同适用约定：每条规则包含必要当前状态、输入、单个直接操作、全部明确动作及对象、字段结果、条件、例外、范围和定位。明确哪些完整规则适用于哪些情境，并声明覆盖后文的概览、文字、图示、例子、模拟、反馈、恢复、自检和编写者核对项；共同规则本身完整且覆盖本处时，后文才可缩写。自然语言或适当表格均可，不强制章节、控件或题量。不能只先列初值、仅给源章节号，或把完整表放在后面并让读者自行猜测前文继承。没有共同规则覆盖的结果必须在本处写足，短句写不全就指向完整规则。源本身无条件的结果不强加新条件，非操作材料仍按其概念、关系及证据组织。

“完成操作”“有效操作”“操作成功”等词本身不补给源必要当前状态、输入或触发；只有源已经完整定义该术语、指南明确给出该定义及本处适用关系时，才能作为缩写。检查的不只是演示正文：概览关系句、图示补充和交付前核对清单也不能省掉使结果成立的必要条件。抽象层级只改变呈现详略，不扩大源关系范围。

正文中的操作结论只由完整源规则组织，不在概览、情境例子、图示连接及其补充说明、重试提示或核对清单自由缩写。每处重述写足必要前提，或明确引用就地声明覆盖该处的完整共同规则；读者不能靠记住旁表、初始面板或上一情境补齐。无法在短句保留完整条件时，改为引导查阅完整规则，不另写省略条件的结果。只有源规则本就无条件时，才可给无条件操作结果；纯条件真假判断不附操作结果时可单谈组合满足与否。材料没有操作规则时不强造规则目录，仍按其概念、关系和证据组织；自然语言或适当表格均可，不要求固定章节、格式或条目数。

恢复与重置逐项分清原材料规则和教材界面设计。完整恢复保留源规定的全部动作、对象、字段结果、范围及现实保证边界，不以初值表代替其他源动作。每处重述可明确引用完整共同恢复规则，并声明覆盖本处情境、段落或题目；仅列初值或清教学反馈不等于保留全部源恢复。图示或小区域只展示部分字段时，明示局部视图并引导完整规则，不声称枚举完整恢复。原文规定恢复的字段及其初值仍按原文保留；教材另设的展示状态、提示、反馈、默认值、清除或失效时机须在该条目处标明“本指南的设计判断”及局部范围。混合清单分别标注依据，不能以段末一个源章节把新增界面清理统称材料规定；别处的总标签或设计章节名也不为本处混合归因补证。教材设计只能管理演示与展示，不增加或撤销源操作结果。

新增界面行为的设计理由与源规范依据分开。源规定的操作、结果和恢复按源定位；展示清理、反馈失效、选中项或高亮恢复等新行为说明教学需要及设计范围，不能同时称其由没有写明该行为的源规则规定、提供依据或保证。前句“设计判断”标签不能抵消后句的源归因。源内容可以启发设计；仅作为素材或动机时明确这是设计者推理，源未规定相应界面行为，不把这种推理写为源规范依据。保持源对象原称呼和缺口，不能将源未定义的动作对象扩写为新界面字段或业务记录。


## 分步演示

采用同一组明确材料贯穿必要步骤，避免每步更换情境造成理解断裂。每步说明当前事实、操作或触发、改变内容、局部结论及来源；分支、循环、暂停、退出和例外保留，不强行画为单一路线。

演示动作与真实动作分开标明。材料规定需要人为触发时，改变参数或满足条件仅更新“可执行／待触发”等判断，不自动显示动作已经发生或成功。教学中的触发、提交、确认或恢复均标为模拟，不向外部系统执行对应动作。

回退时说明回到哪个状态，是否保留已填写内容；重置时说明清除什么及恢复什么。不能把“恢复初始演示状态”写成真实系统一定可以回到最后成功状态。材料没有保证的行为维持未知。

## 条件模拟：先判断规则是否完整

先读出变量、取值范围、前置条件、分支结果、优先关系、例外及适用范围。只有这些足以覆盖所模拟输入时，才给可判定结果；不得把熟悉的业务惯例补成规则。

| 材料状况 | 指南中的模拟边界 |
| --- | --- |
| 完整规则，所选输入均被覆盖 | 可展开条件组合、边界值和例外；每个结果附理由与依据，仍受材料范围限制 |
| 只规定部分分支 | 仅对已规定分支作判断；其他分支显示“材料未规定，结果待定”及缺少的规则 |
| 缺少阈值、取值范围、触发者或结果 | 明确缺失项，不默认阈值或自动动作；可展示缺口如何阻断判断 |
| 规则互相冲突且无适用的优先规则 | 并列冲突和来源，显示结果不能唯一确定；不选最方便的结果 |
| 为教学另加假设 | 另列“教学构造／假设模型”，清楚说明新增假设及其范围；不得把其输出写成原材料结果 |

规则完整与输入有效分别判断。材料规定了允许值时，越界输入反馈为“超出本模拟规则范围”，不混同某个正常分支。材料没有输入范围时保留未知，不发明范围。

建立模拟输入前逐项定位源初值、赋值/运算、可达值、数值类型及完整输入范围。仅能从源流程推出某个保持性质时，把结论限定为该流程的可达值，不提升为所有可接受输入的定义。额外选择集合、上下界或类型限制可作为教学构造/设计判断，但须在起始信息、操作选项及反馈中就地标明局部假设与范围；不将未规定的输入判无效，不把额外限制列成源事实。交叉核对不同段落的限定及归因，另一处正确标注不能抵消此处遗漏。

完整输入值域未知不构成禁止具体输入的依据。先检查该固定输入是否已命中某条局部规则及其全部必要前提；已覆盖的输入和结果继续按源判断。未被任何规则覆盖时才保留待补，不自行宣布无效。教材可选择较小的输入集合或禁止某些演示值，但须就地标为本互动的额外设计限制，不能用“材料未给完整范围”冒充源禁止理由。

输入范围缺口只阻断未覆盖的输入；源流程已明确的当前操作、字段结果或可达性质仍可按其条件判定，不能因通用值域未知把已知局部结果一起抹掉。

对每个要演示的操作，先从原文核对允许的前置状态、必要条件、触发方式和结果，再判断哪些反例可明确写为不可用。不能把某个操作的前置条件套到另一操作，也不能用名称相近的状态代换。逐步演示、成功与失败反馈、重试及自检中的同一操作应使用同一组源条件；不可用反例不得包含源规则允许的状态。出现内部冲突时回查原文修正，规则不足的分支保持待定，不以“通常如此”补齐。

区分“原文禁止”和“原文未说明”。原文只规定一个状态下的操作结果，不等于其他状态必然不可用，也不保证这些未规定分支的状态或数值保持不变。只有原文明确给出必要条件、排他范围或禁止规则时，才写相应确定的否定反馈；否则该分支标为待补规则，并限定本次演示范围。

先按单个操作及确定其结果所需的当前状态组织反馈，再展开其余条件。每个反馈块的标题、表首或紧邻说明必须明确共同前提及其覆盖的全部子分支；若没有这种声明，每个分支自行写足必要状态，不能凭前一行、默认初始面板、旁边的正确表或独立情境默补。条件真假表若给出状态或数值结果，也须有操作及当前状态前提；只有纯条件组合结论时，才可单独讨论组合满足、不满足或未决。

共享互动会更新状态并允许继续或重试时，初始值只约束首步；每次操作取最新状态重新匹配源规则。共同前提范围外先检查其他源规则，已覆盖的结论仍保留，只有未覆盖结果待补；不满足本块前提不自动等于禁止、保持原值或全部未知。逐对代入状态不同但其他条件相同的情形，核对宽分支是否误套或与范围外分支重叠。
先设计尝试生命周期，再写分支反馈：说明进入、当前状态与输入的来源、继续操作、修改条件、重试、退出和复位的具体关系，区分共享连续模拟与独立固定情境。共享模拟每一步从上一步结果取得最新必要状态/输入，固定单个操作重匹配源规则，更新有依据的字段或动作并使旧反馈失效；修改条件不默认为重置当前状态。独立情境每次进入或重试明确恢复所需题设并标明依据和范围，不靠第一次的初始值假定后续复位。源规则缺口不编造变化、保持或清除；有依据的局部结果保留，依赖未决状态的后续路径待定。可返回明确题设或执行有依据的恢复后继续，不把未知操作静默当作已完成或未发生。

纯条件真假比较不附源操作或字段结果时可独立判断组合，无需强加材料不存在的业务状态；一旦给出操作后结果就按完整当前状态和操作规则判断。完整关系及排他判断覆盖影响同一字段的全部相关源规则，包括源恢复、重置和例外；没有源明示或完整局部枚举支持，只陈述有据的正向关系，不合成全局“只有/唯一/始终”。段落引用是依据，不能自动替排他断言限定范围。


若无法把动态反馈的覆盖范围写清，可采用互相独立的固定情境：在该情境处明示必要题设、适用分支、每次尝试如何复位及局部范围，不暗示继承上一情境状态。情境只能补齐标明的教学假设，不能补造源规则；既有源规则不足时仍给有边界参考或待定。设计选择不声称已经实现或测试，不要求固定表格、控件或无关字段。

固定当前状态和单个操作后再判断。某状态下直接执行一项操作，与先经过其他操作改变状态后再执行，是不同的问题；后者路径缺规则，不撤销前者已由必要条件、排他范围或禁止条款确定的结论。不能用“再次操作甲或操作乙”等一句话，把各自有不同依据的操作统判允许、禁止或未知。拆开操作和路径，分别写已知条件、结果与缺口。

每一条“未规定/待补规则”先固定当前输入和单个操作，再逐条检查原材料是否已有更宽规则覆盖它。源规则不必逐一列出所有特例；已有覆盖不能因为未单列重复、某字段已是结果值、动作看似无意义或没有额外提示而变成缺口。只有原文明确的前提、排除和例外才能改变允许范围。仍符合源条件时给出规则确定的字段结果，即使结果等于当前值；操作的额外意义或展示提示若未规定，单独保留该缺口。若宽规则本身条件不够明确或与适用规则冲突，保留真正缺口，不擅自扩大覆盖。

对重复尝试，先取上一步后的当前状态，再重新匹配源规则。仍满足同一允许条件且没有明确限次或重复例外时，沿用该规则规定的结果；不擅自加入“当前值必须有效”“只能执行一次”等新前提。赋值后的值与当前值相同，仍可说明确定的字段结果和变化量。额外重复提示或特殊界面反馈未规定时，只标该反馈缺口，不能将已确定的操作、状态和数值一并判为未知。

新增排他量词只有两种依据：原文明确支持该局部范围的排他性，或完整枚举该范围全部相关规则后确能证明。枚举包含常规动作、恢复、重置和例外对同一字段的影响；不确定是否完整时沿用非排他的源结论，不能新增“只/仅/其他不可”。每处排他断言就地给范围，标题、关键边界、核对清单和附录同样要求；远处正确提到恢复不能替本处补限定。

范围必须保留原对象与谓词。某物件、规则或事项不在说明范围，不等于其持有者或执行者在其他已覆盖事项上也不适用。不能将对事项的排除改为新读者身份前提或资格条件；若教材另设读者子集，标为设计选择，不归因于原材料。

交付前逐处核对正文、模拟表、反馈、边界说明、恢复和自检中的操作断言，重点回查“允许／不可／只能／未规定”。同一当前状态和单个操作的归类应一致；仅路径未规定时把未知限定到该路径，不把源规则明确覆盖的直接操作重新列为未知。

组合条件中的“未知”表示现有信息不足，不自动成为原规则新增的业务取值。先逐项区分已满足、明确不满足和未知，再按原文关系合并：对“且”，任一必要项明确不满足已足以判该组合不满足，其他项未知不能撤销此结论；对“或”，任一备选项明确满足已足以判该组合满足，其他项未知不覆盖此局部结论。其余含未知的组合按缺失信息保留待定，全部已知的组合按原文判断。

上述判断仅针对原文明确给出的条件组合，不代表整个操作可执行、动作已经发生或其他状态、数值可以确定。模拟表和反馈中的分支应互斥，或清楚说明优先顺序；“任一未知”不能同时覆盖已由明确满足或不满足决定的分支。不要为填满表格而把局部可判定结论一概改成未知。

回查全文每句信息不足提示，不能只检查表格中的已知组合。对“任一项未知就不能判断”等宽泛句，逐项代入另外必要项已明确不满足（且）或备选项已明确满足（或）的情形；保留可判定的局部组合结果，把未知限制到仍未决定的部分。文字边界、自检反馈和恢复说明使用同一合并规则。

逐对检查模拟表的条件覆盖关系：含“任意／其他”的宽泛行是否同时命中更具体的组合？若作为操作分支，拆成互斥条件或明确优先；若要累积多项原因，另列反馈清单并注明同时合并适用项。不能按第一条宽泛匹配就丢掉其他已知缺项或未知项说明，也不能用表格排版暗示未声明的匹配规则。

教学构造只用来帮助解释，不能用来填平原材料冲突、消除未知或冒充事实依据。必要构造可简短而明确，仍保持所有源规则限定。原规则缺失但完整教材任务可以继续时，模拟相应部分保持待定，不影响有依据的部分。

指南中的示例输出应包含当前输入、命中的规则或未规定分支、局部结果、限制与恢复方式。“满足前置条件”不能自动变成“验证成功”“动作完成”或“业务通过”。

## 教学自检：先判断判准是否可靠

为每个自检指定要练习的理解问题、材料依据、适用条件与反馈边界。

逐题列清确定反馈所需的当前状态、输入和假设，只列有关字段；共享默认须明确说明适用于哪些题及如何被题中条件覆盖。题名、教材初始面板、上一案例或另一题不自动提供本题前提。可明确补齐局部题设的状态/输入假设并标注；已有源规则足够覆盖时，只在该假设范围内给确定反馈，不把假设冒充事实或补造源规则。必要前提仍缺或判准不可靠时，给条件化参考/待补信息，不给唯一确定答案。题干、判准、理由、误区和重试都用同一前提集合；只在别处写对源条件不能补救本题遗漏。

**有可靠判准时**：答案或判断由明确且适用的材料支持，问题具有可核对的结果；如有多种成立答案，判准应容纳它们，不能为单选形式强造唯一答案。指南说明提交后显示局部判断、理由、常见误区、来源定位和限制，并允许改答、重试或重做。

**没有可靠判准时**：缺少定义或规则、来源冲突、开放设计取舍、答案依赖尚未取得的情境时，采用开放说明与参考思路。参考标明依赖的假设、哪些思路可成立、尚不能判断什么；不伪造标准答案，不自动标正确／错误，不评分。可以让读者说明依据、指出差异并修订，不把未经评阅的自由文本写成已核验。

题目不预选或推荐正确答案，不因沉默、超时或窗口消失推进；目标选择阶段的推荐不能迁移成自检的答案提示。空答或无效答复保持待答，提示需要明确回答，不作为知识错误。

修改答案后，旧判断清除或明确失效；重新提交按当前答案给反馈。重做说明清除哪些选择和反馈，并保留返回材料的方式。允许在看过反馈后再练习，但提示后改答只支持当次反馈后练习事实，不追写为此前已经掌握。

自检设计可以用“已核对”“已提交”等局部状态，不用总分、能力等级或“已掌握”替代观察。一次答对、完成全部操作、表达信心或愿意点击都不能产生长期能力或稳定掌握结论。本技能只描述教材中的自检，不在聊天自动开始测验。

## 交互核对

交付前对指南中实际采用的每项交互检查：用途对应已确认目标；内容和变化有来源；关键条件与限制可见；结果与证据类型一致；完整和缺失规则分开；可靠和不可靠判准分开；反馈解释理由并支持恢复；模拟与真实操作清楚区分。

有需要时在指南中提出后续检查任务：新情境下解释下一步及依据、核对遗漏、定位来源、观察无效操作或往返查找。描述未执行的检查时使用“拟检查”或“需要检查”；不把这份设计、模型演示、局部自检或静态审查写成目标用户理解改善的实证。
