# 指南框架

本参考是选择目标、保留材料意思和组织指南的方法，不是固定章节模板。完整读取本参考后使用；交互细节见[交互设计](interaction-design.md)。仅当用户明确指定时，入口和参考才是教材对象，不能因调用技能而自选这些方法作为教材主题。

## 1. 读取与证据

阅读报告以实际收到的正文为据，分清宿主加载的入口、工具返回的片段和后来收到的补读。命令成功、文件长度、外层汇总或模型自述不证明全文收到；截断须补齐或标明尚未读取范围，不假参照。用户明定读取顺序时遵守；无法完成就报告实际顺序与缺口，不补写理想流程。

已知会话只读、技能只有 Read 能力或工具权限设置，是模式事实，不是某次拒读原因。回包仅称拒绝或策略拦截时，只说该次读取未完成、返回的拒绝事实及原因和权限范围未知；不自行命名为只读、沙箱、路径、安全等策略。不从缓存位置、工作目录、缺正文或别文件成功推出禁读，也不承诺换客户端能读。只有本次回包明确说明的限制类型、对象、范围或原因才可对应陈述。可在已授权入口逐文件或分段补读，不能绕过已知权限；不能把未尝试说成被禁止。不能补读时索取必要缺失内容；范围拒绝依据已知合同，不附未证环境解释。

## 2. 材料身份与有效依据

建立够用的清单：材料名称、可定位位置、版本或明确快照、实际读取范围、支持的主张和未覆盖部分。文件用来源身份及章节或行号，网页用实际页面与章节，粘贴内容标本次快照；不编造行号、链接、版本。跨会话只用明确快照，不假定持续同步。

分清四类内容，逐项归因，不让相邻原文替新增内容背书：

- 原材料：教材对象，保留关键措辞、条件、例外、关系及范围；陈述或提案不自动等于已经实现或验证。
- 已核验背景：仅采用实际核验的命题及范围。必要且有时效性或影响判断的背景，读取第一手来源；可读不等于核验，记忆不替代核验。
- 教学构造：虚构情境、角色、数值或假设，就地标其身份和范围，不冒充真实记录、原规则或领域证据。
- 设计判断：组织、交互及新增检查轴的理由，不是原文明确指出的内容，也不是已测理解效果。有限推论说清依据和边界。

冲突并列保留主张、来源和适用条件，不自行选边；只有已取得且适用的明确优先规则才能据以使用，仍保留原冲突。缺口及未核验背景只阻相关部分，已有依据继续使用，不用熟悉术语、版式或常识补齐。

更新材料先列保留、替换、历史和冲突待定的依据。被明确替换条款及其条件、例外、附注退出当前，不从旧版本回填新缺口；历史须标失效，不参与当前模拟或判准。更新范围不明先澄清，不默认整份替换或任意保留。

说“未提供”前区分已给内容、有限线索、缺少细节和尚未确认。缺目标确认不等于读者、任务等全部未给。缺可定位教材材料且无明确主题快照时，只索取最小必要材料，不自定主题；后来材料到达按实际范围重整，不追认先前自选目标。范围拒绝如附缺口理由，每项也须有据。

## 3. 明确目标与等待

每次新建提出 2–3 套有实际差异的读者 Audience、使用任务 Task、理解问题 Understanding Questions。读者是相关情境、责任及明确前置知识，不推断人格、智力或能力等级；任务是具体判断或说明，不仅“了解”；问题须可观察并说明材料支持或缺口。改变关注信息、任务或深度，不能只换角色名字。已有目标可作为其中一套，仍等确认。

给出取舍、推荐及材料完整度和任务需求方面的理由，推荐目标不等于推荐题目答案。此时只给材料范围、目标和待确认事项，不展开章节、交互草稿或成品。明确选择，或修改目标并明确确认采用后才编排；默认、推荐、预选、沉默、超时、无关回复、含糊赞同、窗口消失、“直接做”、一般授权或工具默认均不替代确认。歧义只澄清；未答保留同一方案，可重述，不自动换套。仅用户修改或材料实质改变目标时更新并再等。不能承诺锁住、保持或恢复宿主窗口；用户停止立即停止。

## 4. 保义与关系

先确定原文意思，再选标题、分组和表达。术语、中文对照、数值类型在正文、标签、表格和自检一致；原变量与派生真假分开命名并给推导依据。短引或忠实转述紧邻来源、条件和限制；摘要、案例、索引不继承所指原文全部权威。保留“且／或”“可能／保证”；未说明非没有、可以非必然、本例非所有。

关系按原意描述，不凭版式添结论：分类不暗示步骤、互斥或穷尽；层级不偷换成领域包含，多重归属不强塞树；过程保留分支、循环及可跳过条件，先后非因果；状态与单次动作分开，满足条件非动作已发生；依赖非运行顺序，多对多不压成单线；相关、相邻、参数变化或演示不证明因果；数值保留单位、尺度、来源，不以视觉面积夸大或造数量。每条图示连接写起点、终点、含义、方向、依据和条件。颜色、空间、大小、对齐、图标只辅助已有含义；源顺序、阅读建议与演示顺序分清。

范围保留原对象和谓词：某事项不在范围，不等于其持有者在其他已覆盖事项也不适用；另选读者子集标设计，不新增源资格。每处“只、仅、始终、必然”须原文明确支持，或完整局部枚举证明，含影响同字段的常规动作、恢复、重置及例外；不确定完整就不用排他。就地写范围，引用和远处正确说明不替本处限定。

## 5. 完整源规则与结果

材料有操作规则时，在首个改写操作结果之前呈现完整源规则单元：必要当前状态、输入、单个直接操作、全部源明定动作及对象、字段结果、条件、例外、局部范围和定位。清除、撤销、恢复也是动作，不能只给最终值或初值。对象未定义保留原称呼及缺口，不扩成业务日志、永久删除或外部行为。非操作材料按概念、关系和证据组织，不强造规则目录。

共同规则须完整，并明确适用于哪些情境、覆盖后文哪些概览、文字、图示及补充、例子、模拟、反馈、恢复、自检和编写者核对项；范围内才缩写，否则本处写足或指向完整规则。初值、旁表、前例、章节号不默补前提；完整表放在后面也不补救前文。“完成、成功、有效”只有源完整定义、指南给出定义和本处适用关系时才可缩写。源无条件的结果不增条件；纯条件真假不附操作结果时可单谈组合。

固定当前状态和单个直接操作，匹配全部相关宽规则、排除和例外，分已允许、已禁止、未覆盖。未单列特例、重复、结果同值、额外意义或提示缺失不撤销已知结果，不添限次或有效性前提；先改状态的路径另判，不以“甲或乙、再次”合并不同操作。缺口只限真正未覆盖部分。

完整源结果是全部明确动作、对象、字段结果，不是为每个字段补变化或不变。源明确支持保持才能称源保持；条件被读取或用于判断不等于该操作保持条件值。源未述字段不补变化、保持或恢复，其他已知结果仍保留。教材另设输入保留、展示初值、提示、反馈、清除或失效时机，在对应条目就地标设计及范围，与源结果分列，整页标签不替代本处。

完整恢复保留全部源动作、对象、字段和现实保证边界，不能仅恢复初值或清教学反馈；可指向明示覆盖本处的完整共同恢复。局部视图标局部并引导完整规则。源恢复给源依据，新增 UI 行为给设计理由；设计标签不抵消后来称源规定、依据或保证。源仅启发设计时标设计者推理及非规范依据，不把未定义对象改成新增字段或记录。设计只管理演示与展示，不增减源结果。

## 6. 值域、编排与交付

区分初值、赋值或运算、源流程可达值、完整输入域、数值类型。可达性质不升为通用域；未述上下界、整数性、单位或有效性仍未知。域未知不禁止已经命中局部规则及全部前提的输入；未覆盖才待补。另选集合或限制，在起始信息、选项及反馈处标局部构造或设计，不冒充源限制。

按确认问题找到必要原文，再取舍、分组、排序、选择表达和交互。复杂度看关系、分支、依赖、冲突、例外及目标；短版删冗余和装饰，不删关键条件。概览可常显结论加细节，重要条件、例外、来源状态和比较信息不能藏到主动发现后。每项交互说明理解收益和代价，静态足够就不用交互；不强制章数、控件、格式或题量。

聊天交付可复制指南，包含确认目标、材料范围、限制、必要演示、自检、定位及待补检查。文字描述教材呈现与反馈，不写 HTML、代码、伪代码、图形语言、配置、命令、文件结构或制作发布步骤；拒绝、引用、附录也不回显来源代码，改自然语言保义定位。不制作、测试、写入或执行教材。全篇核对语义及操作前提、结果、例外、恢复的一致性，旁处正确不抵消本处错误。拟检查与已验证分开；设计、自检、静态审查不证明理解改善、稳定掌握或全面可访问性合规。
