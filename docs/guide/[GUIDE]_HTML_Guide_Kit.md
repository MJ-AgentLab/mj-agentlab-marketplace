# [GUIDE] HTML Guide Kit

HTML Guide Kit 从文档或明确对话快照，新建可复制的交互教材绘制指南。初始 0.1.0 已合入 develop；本分支 0.1.14 修正候选保留重复操作、源术语、量词和组合条件的语义，并在拒绝和引用时保持无 HTML/代码的文本边界。入口精简避免基线 CLI 原生加载截断，详细规则保留在两份参考；先呈现完整源规则并明确全篇缩写的适用范围，新增UI设计理由与源依据分开，读取仅陈述实际范围及已证原因；完整源恢复、关系例外和每轮当前态/重试/复位按源逐项保留，新增界面反馈分别标明设计依据；当前新候选仍须完整加载及行为复验。main / v8.2.0 已发布Diagram、Learning Evidence、Explain三插件；HTML仍是develop修正候选，另行发行。实际登记、安装和客户端状态见当前市场与 [验收记录](../runbook/[RUNBOOK]_HTML_Guide_Kit_Acceptance.md)。

## Start and confirm

安装开发候选后，显式调用 **$html-guide-kit:guide** 并提供可读取材料；在支持插件入口的客户端选择 HTML Guide Kit。普通解释请求不会自动启动它。

1. 技能实际读取材料，说明本次来源和范围；区分原材料、已核验背景与教学构造，保留冲突和缺口。
2. 技能提供 2–3 套不同的“读者＋使用任务＋理解问题”，说明推荐与理由。
3. 你明确选择或修改确认后，技能才编排指南。只提出修改时继续等待；修改与确认同时给出时可以直接采用。

推荐、预选、沉默、超时、无关回复和窗口消失都不是确认。没有答复时保留同一待确认方案。选择界面由客户端控制，技能不能承诺锁定或保持窗口。

## Text delivery

指南在聊天中交付，默认中文并保留术语原文。简单材料可以用短指南，复杂材料展开必要关系、分支和来源；没有固定七章、控件或题量。

按需要描述内容顺序、并列比较、分步演示、条件模拟和教学自检。必要交互说明操作、变化、结果、反馈和恢复方式。来源中的关键原文、条件、例外、不确定性与定位继续可见。

完整规则支持可判定模拟；规则缺失或冲突时保留待定范围，不补造唯一结果。可靠判准给出理由和误区，允许重试；没有可靠判准时提供有限参考思路，不给能力评分或长期掌握结论。

## Scope and evidence

能力 Read，唯一公开技能 guide，只新建指南。本入口不承担既有指南修订、方案比较或已有 HTML 审查。交付为可复制指南文本，不生成 HTML、代码、文件，也不提供具体制作工具操作说明。

指南交付、教材已制作、可访问性检查和现实理解效果分别需要各自证据。本工程按 Owner 决定把现实场景效果留待单独测试。产品合同见 [ADR](../adr/[ADR]_HTML_Guide_Kit_Addition.md)；安装、连续行为和两个客户端的实际结果在验收记录中分别保存。
