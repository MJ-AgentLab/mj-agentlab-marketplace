Library Renewal · 续借判断学习制品

Audience · 目标读者
能够读懂基本日期，但尚未区分规则许可、申请提交与完成确认的学习者。
Task · 使用任务
根据本页自编规则，解释续借是否允许、成功或失败后的日期，以及确认完成所需依据。

Understanding Goals · 理解目标

  • 用两个必要条件的组合解释规则许可，不把且改为或。
  • 从原到期日计算成功后的七个日历日，失败时保留原日期。
  • 区分提交、成功确认与未知结果，并指出确认所需的两项依据。

Understanding Effects · NOT_MEASURED。页面、工程检查和本题核对各按实际范围报告，理解效果尚未测量。

Overview · 先区分三个判断

本材料使用项目自编的图书续借规则，帮助核对条件、日期与完成依据。它不是任何真实图书馆政策，不连接图书馆或提交真实申请。

Rule Permission（规则许可）说明规则是否允许本次续借。Submission（申请提交）说明已提出申请。Completion Confirmation（完成确认）说明哪些可见依据足以确认成功；三个判断不能互相代替。

Necessary Foundations · 条件与日历日

本练习只处理一本书的一次续借。两项条件用“且”连接，表示必须同时成立，不能满足一项就视为全部满足。Calendar Day（日历日）按连续日期计算，周末和跨月也计入。

完整原件在 Synthetic Renewal Rules，以下解释对应 LIB2–LIB4。

Rule Permission · 同时核对两项条件

尚未逾期且没有其他读者预约时，本练习规则允许续借。任一条件不满足，就不能按这条规则续借。规则允许不表示申请已经成功。

Date Outcome · 从原到期日计算

按 LIB3，续借成功后，归还日期在原到期日基础上延后七个日历日；续借失败时，原到期日不变。

  • 原到期日 2026-10-20：成功后为 2026-10-27；失败时仍为 2026-10-20。
  • 原到期日 2026-10-29：成功后为 2026-11-05；失败时仍为 2026-10-29。

规则没有用申请日计算，也没有排除周末。日期结果需要已知成功或失败；结果未知时，不能自行选择其中一种结果来改写到期日。

Completion Confirmation · 保留未知结果

按 LIB4，点击“申请续借”只表示申请提交。页面显示“续借成功”并更新归还日期后，才能确认续借完成，两项依据必须同时出现。

没有成功确认不等于已确认失败。规则未提供完整后台状态机，也没有说明等待时长；不要自行补造审批步骤或超时失败。

Integrated Practice · 说明你的判断

阅读下面的局部练习时，可以回查正文与来源。先写清当前给定条件，再解释规则、日期和完成状态分别能确认什么。修改答案后重新核对，不能沿用旧反馈。

核对与反馈只对应这些教学题。页面可操作或一次答对，不能证明长期掌握、迁移能力或设计改善了理解；Understanding Effects 保持 NOT_MEASURED。
