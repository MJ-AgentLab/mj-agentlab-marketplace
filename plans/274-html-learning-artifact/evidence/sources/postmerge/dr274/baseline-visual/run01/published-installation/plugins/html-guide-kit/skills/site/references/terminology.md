# Terminology Reference

本表是包内术语正本。每个制品在 artifact.json 的 terms 保存本主题所需映射，正文、图表、控件、反馈、导出使用同一名称；来源已有技术标识、命令和文件名保留原文。没有稳定英文名时建立明确映射，避免临时替换；不同概念保持区别。

| English Name | 中文解释 |
|---|---|
| Audience | 目标读者及相关背景 |
| Task | 需要完成的判断或行动 |
| Understanding Goals | 学习后能展示的理解能力 |
| Observable Questions | 用于观察表现的检查问题 |
| Answer Criteria | 有来源依据的回答判准 |
| Information Structure | 信息分组、层级和阅读安排 |
| Relationship Representation | 对分类、依赖、状态等真实关系的表达 |
| Semantic Fidelity | 忠实保留材料含义、条件及边界 |
| Exhibit | 对应展示；图表或示例本身不自动成为证据 |
| Evidence | 支持具体主张的证据 |
| Source-supported | 来源支持关系，确认来源说了什么 |
| Confirmed | 在声明范围内已有核验依据的具体主张 |
| Verified | 指定检查已实际验证 |
| Completed | 约定任务目标与必要验收已完成 |
| NOT_MEASURED | 没有开展相应学习者效果测量 |

核心概念、执行阶段和主要章节采用英文名并邻近解释；正文推导、条件、案例、练习、误区、反馈和操作提示使用中文，如“查看依据”“核对判断”“重新开始”。中文用足够的解释保留细节，不为简短而改变含义。forbidden 只列本主题明确判为误用的写法，不能把词面通过当语义正确。
