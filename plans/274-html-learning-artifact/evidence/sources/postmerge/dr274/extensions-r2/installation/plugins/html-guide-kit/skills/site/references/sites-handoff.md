# Sites Handoff

Sites 是唯一必需的外部制作能力；本地方法独立不表示模型或托管离线。按目标宿主实际技能目录发现 Sites，读取**当前安装版本**的工作流及需要的本机预览/源码/发布参考，再调用实际提供的工具。路径或工具缺失时保留交接包，明确制作/发布未完成；不编造连接器ID、MCP地址或manifest依赖字段，不自动下载替代品。

## Bounded production package

先核对包只包含明确选定内容：Audience/Task/Understanding Goals及已确认范围；Markdown正文、主题术语和必要来源；信息结构/关系说明、交互用途/状态/反馈/恢复/静态替代；本地主题与选用组件；检查问题/判准/依据；内容版本、文件/哈希清单、未决事项和最小验收。简单任务可合并为 artifact.json 与正文/来源，额外设计记录按真实用途保存。源码包不能包含整个工作区、旧Site身份、凭据或历史通过记录。

生成器是本地静态基线，Sites依据同一材料制作与发布；复杂组件可在Sites工作区按已确认设计实现，再执行受影响检查。渲染器不承担托管、认证或凭据能力。

## Actual execution

1. 明确新建或更新对象；读 `.openai/hosting.json`，已有project_id就复用。新站默认私有；更新保留身份和受众。创建结果未知先回读，避免重复创建。
2. 在任务独立目录准备本地源码。简单页面优先buildless HTML/JS，生成输出置于Sites要求的静态目录；按当前Sites工作流处理源码仓库、hosting配置、依赖和打包，保持完整交接材料。
3. 先做内容/结构/本地检查和代表主流程。使用本地字体/样式/脚本，无CDN或自动运行时安装。浏览器不可用如实记未查；核心失败先修复。
4. 通过当前Sites源码helper同步**精确**状态并取得实际commit_sha及archive，再保存该版本并部署。凭据只在会话内存和要求的隐藏stdin传递，不入源码、参数、日志、包或证据。工具返回saved_version_id时继续该版本，不重复保存；部署未知回读，不重复创建。
5. 读取实际结果，核对project_id、保存版本、源码commit、部署状态、真实URL及受众。pending/building/publishing按当前流程跟进到终态；成功URL不替代内容/交互检查。

发现身份/受众不符、凭据或非预期材料时停止发布并按实际状态修复。保留受影响版本/失败范围和恢复依据；站点公开或扩大受众须有对应用户授权。

自有Marketplace安装/入口发现和实际Sites调用需真实主流程证据。工程会话已有Sites工具不自动证明安装后的入口能调用；分别记录安装来源、技能locator/版本、调用方法、目标客户端、工具结果及限制。不把公共目录和Git/本地Marketplace可用范围互相推定；公共目录上架资格未验证。
