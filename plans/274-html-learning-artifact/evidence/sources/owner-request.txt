## My request:
实施该计划，遵循最新的 plan 机制。实施原则：

## 1. Agent 执行，Owner 决策

Agent 承担技术操作；Owner 只补必要信息、作实质决定与授权。Owner 默认从成品结果出发验收，不参与常规构建过程审查。\


## 2. 独立合成验收

Agent 模拟相关角色并独立核验功能与工程质量，使用可复现的运行证据；不要求真人参与模拟验收，但不替代 Owner 的最终接受。\


## 3. 严格窗口，分段交付

保留严格窗口条件；缺少非核心能力时，延期对应入口，核心通过自身验收后可先交付。延期事项不得视为通过。\


## 4. 集中授权，条件复用

对明确范围集中授权；目标、对象、环境、权限和风险边界未实质变化时复用授权，越界时重新授权。\


## 5. 可执行约束，证据驱动

Harness 自动执行必要的工程质量门禁。Agent 自主验证与修复，以可复现、可追溯证据支持验收；证据不足不得宣称通过。\


## 6. 风险隔离，可控恢复

Agent 自主执行不得越过技术权限边界。不可逆操作须满足专门控制条件；已发布变更须具备与风险相适应的监控及恢复能力。\


## 7. 单 Issue、单主 PR、多子 PR

使用单 Issue、单主 PR、多子 PR 的模式开发。主 PR 以 develop 为目标，遵守受保护分支的要求；多个子 PR 以主 PR 所在分支为目标，该分支不受保护，Agent 可以执行子 PR 的合并。\
