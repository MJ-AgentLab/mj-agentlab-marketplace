# HTML Guide Kit 第一轮图标候选

状态：**已被第二轮替代，未获选**。Owner 明确要求“重新设计icon，结合 HTML和教学两个元素”。本轮 A、B、C 的源图和导出图保留为历史，未进入插件包、市场登记或正式导出清单。当前待选择对象是 [第二轮候选](revision-2/README.md)。

目标功能是新建可复制的交互教材绘制指南文本。图标表达材料的学习编排，不使用代码符号，也不表示技能会制作或写入 HTML。三个候选均使用共享品牌参数中的白色圆角底、深蓝／蓝／青配色、左上至右下渐变、安全留白和厚实几何形。

| 候选 | 功能符号 | 主要影响 |
| --- | --- | --- |
| **A：教材路径（第一轮推荐）** | 开放书页内贯穿三个学习步骤 | 教材轮廓最直接，32 像素时书页仍清楚；路径体现内容关系和学习推进，最贴近指南整体功能。 |
| B：学习导航 | 折叠地图及两端路标 | 强调读者在内容与使用任务间的导航；地图更通用，可能先被理解为路线服务。 |
| C：分步演示 | 层叠教材卡片及前进箭头 | 强调逐步演示和状态变化；步骤辨识清楚，但容易先被理解为文档顺序操作。 |

源文件为 [a.svg](a.svg)、[b.svg](b.svg)、[c.svg](c.svg)，均可编辑，无嵌入位图、系统字体或外部依赖。对应 a.png、b.png、c.png 为 1024×1024 导出图。

[总览](overview.png) 将九种小尺寸分别以实际 32、48、64 像素显示在深浅背景；`*-32.png` 等保留透明角区，`*-32-light.png`、`*-32-dark.png` 等为对应像素大小的背景合成图，没有放大冒充小尺寸。总览中的大图仅用于比较整体轮廓。
