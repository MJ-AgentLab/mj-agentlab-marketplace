# HTML Guide Kit 第二轮图标候选

状态：**Owner 已选择第二轮 A：HTML 教材**。2026-10-12 Owner 明确要求“重新设计icon，结合 HTML和教学两个元素”。本轮继承已批准的 D 风格，并重新结合 HTML 成对尖括号与教学符号；Owner 随后明确选择“A：HTML 教材（推荐）— 开放书页＋尖括号”；B、C 未获选。选择依据与准确资源哈希见 [selection.json](selection.json)。此前推荐本身不构成批准。

HTML 尖括号表达指南面向的交互教材媒介；书页、教学板和课程卡片表达教学用途。它们不表示公开技能会生成 HTML、代码、文件或执行制作工具。已按所选 A 准备包内正式导出，但暂存在仓库外；PR2 将在 PR1 实际合并后的最新 develop 原子接入包、manifest、市场登记与正式导出清单。

| 候选 | HTML 与教学的结合 | 主要影响 |
| --- | --- | --- |
| **A：HTML 教材（推荐）** | 成对尖括号分别落在开放书页内 | 两种元素在 32 像素下都直接可见；书页轮廓最贴近教材指南，整体简洁。 |
| B：HTML 教学板 | 带双脚画架的教学板，板内展示成对尖括号 | 强调课堂讲解与演示；支架增加教学情境，整体更宽，重心靠上。 |
| C：HTML 课程卡片 | 层叠的课程卡片，首页含成对尖括号与内容行 | 强调教材单元及分步组织；层次鲜明，小尺寸内部结构比 A 多。 |

三套轮廓分别是开放书页、双脚教学板和层叠卡片；均使用 1024 方形画布、白色圆角底、深蓝／蓝／青配色与统一的左上至右下渐变。尖括号线宽统一为 72，主体厚度和留白按品牌参数设计。所有图形都是独立可编辑 SVG 路径或几何形，无系统字体、嵌入位图或外部依赖。

源文件：[a.svg](a.svg)、[b.svg](b.svg)、[c.svg](c.svg)。1024×1024 导出图：a.png、b.png、c.png。

[总览](overview.png) 同时呈现整体轮廓与实际 32／48／64 像素的深浅背景预览。`*-32.png` 等保留透明角区，`*-32-light.png`、`*-32-dark.png` 等是对应实际像素大小的背景合成图；没有放大图冒充小尺寸。
