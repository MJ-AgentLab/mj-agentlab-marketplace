# Design prompts

Read the [brand standard](../../docs/rule/[STANDARD]_Brand_Identity.md), [tokens](tokens.json) and the real target functionality before using these prompts. Vector SVG is the editable source; a raster concept is only a preview.

## Plugin candidate

Create a square MJ AgentLab plugin icon for **the verified target function**. Inherit the approved D design: substantial rounded geometry, white rounded tile, navy #223D66, blue #126CB0 and cyan #37C3D2. Use one recognizable functional silhouette, sparse connection nodes and a consistent upper-left to lower-right gradient. Follow the shared safe inset and connector weights. Inspect native 32, 48 and 64 pixel previews on light and dark backgrounds. Show 2–3 meaningful candidates and wait for the owner's selection before connecting a new design to a manifest. Reuse an existing explicit approval directly.

## Marketplace candidate

Preserve the supplied team's recognizable MJ letter silhouette. Replace the dense glowing network with a few sturdy rounded modules joined by simple connectors, communicating discoverable, composable plugins. Use the same D colors, white tile and gradient direction. Keep the MJ letters readable at 32 pixels. Modules represent an extensible ecosystem rather than a fixed inventory or any one plugin's function. Produce three alternatives within the selected MJ + module-node direction; show their arrangement tradeoffs before final selection.
