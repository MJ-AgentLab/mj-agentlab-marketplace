# HTML Guide Kit

0.1.39 为选择性统一候选（当前公开0.1.38随v8.3.3交付），提供两个显式入口：

| 入口 | 交付 |
|---|---|
| **$html-guide-kit:guide** | 明确读者、任务和问题后，新建聊天中的教材指南，保留只读边界 |
| **$html-guide-kit:site** | 从材料与理解目标制作中文学习网页，保留本地材料和检查；按约定本地交付或通过 Sites 发布 |

site 采用六步制作流程，核心名称用稳定英文并邻近解释，内容、学习活动和控件默认中文。方法、可选主题与工程工具随包分发；关键设计未决时按需读取 Matt grilling，解决后简述并确认设计共识，已确认决定复用。现有材料只读，允许独立目录产物。默认新建私有 Sites，更新保持身份/受众；明确约定本地可按本地成果验收，不自动因 Sites 缺失改模式。必要答案严格待答，窗口持续显示仍延期，文字pending不算通过。

包级 Read/Write 支持 site 的明确制作行为，两入口各自遵守行为合同。使用方法与四项最小门槛见[site入口](skills/site/SKILL.md)和[输入说明](skills/site/references/input-contract.md)。安装、真实Sites流程、保护合并、市场发布和Owner接受按任务证据分别判断。未测理解效果保持 NOT_MEASURED。

以下为保留的 guide 方法与边界；guide 自0.1.36以来的四份运行资源保持原字节，历史结果按对应版本记录。

从文档或明确对话快照，新建可复制的交互教材绘制指南。guide 方法沿用 0.1.36：先读取材料，提供不同的读者、任务和理解问题，明确确认后才交付聊天文本；逐份只读，保留原条件、来源、未知及教学构造边界，先核源规则覆盖再分列已知判断与未知字段，区分源恢复和新增教学结果，并按明确篇幅上限核对全稿。逐原规则保全前提、动作、对象和字段，分别核对源限制与教学选择；局部恢复关系继承完整恢复单元，从源到表示检查遗漏、从表示回源检查新增判断的依据。操作许可与目标结果、恢复动作与相同终值分别核对，不凭一种路径推出唯一入口；局部关系不完整时采用忠实文字或完整规则单元。源条件与源初值不自动成为另设情境的实际题设；缺判定必需信息时明示教学假设或保留依赖结果未知，候选问题也核对许可与成功结果的预设。完整条件判准按各结论的实际且/或依赖求值，另一项未知不撤已知项已决定的结果；仅仍依赖缺项的结论保未知，不把纯必要条件当充分判准。判断前先区分当前一步的许可或结果与实际提出的多步路径存在或不可达；仅对后者核同范围内的源完整动作、恢复与可串接后继，逐步代入前提。缺项只阻仍依赖它的结论，不撤已有路径，不虚构条件改变或目标成功；未教未画不当源未给，不能支持整体否定时收窄到已核范围。原逐对象保已知、共同题设与完整恢复归属等方法保持，不增加固定模板或穷举要求。正式发布、安装与客户端状态见验收记录。

guide 入口为 **$html-guide-kit:guide**，保持 Read 聊天边界，仅显式调用。默认中文，保留术语原文。

显式调用后，技能实际读取材料，保留来源、条件、例外、冲突与缺口，给出 2–3 套不同的“读者＋使用任务＋理解问题”及推荐理由。你明确选择或修改确认后，它才编排指南；没有答复会保留同一待确认方案。推荐、预选、沉默、超时、无关回复或窗口消失都不是确认，技能不能承诺锁住宿主窗口。

指南深度按材料和任务调整，可描述内容顺序、关系表达、分步演示、条件模拟和教学自检。每项必要交互说明操作、变化、结果、反馈和恢复方式。可靠判准提供理由与误区；缺判准给有边界的参考思路，允许重试，不作能力评分或长期掌握判断。

交付物为聊天中可复制的指南文本。本入口只新建指南，不提供指南修订、已有方案比较或已有 HTML 审查，不制作 HTML、代码或文件，也不提供具体制作工具操作说明。

公开方法保存在 [guide](skills/guide/SKILL.md)、[指南框架](skills/guide/references/guide-framework.md) 和 [交互设计](skills/guide/references/interaction-design.md)，均随包分发，相对实际安装的技能定位，无个人路径或其他项目依赖。
