# HTML Guide Kit

从文档或明确对话快照，新建可复制的交互教材绘制指南。版本 0.1.33 为 develop 修正候选：先读取材料，提供不同的读者、任务和理解问题，明确确认后才交付聊天文本；逐份只读，保留原条件、来源、未知及教学构造边界，先核源规则覆盖再分列已知判断与未知字段，区分源恢复和新增教学结果，并按明确篇幅上限核对全稿。逐原规则保全前提、动作、对象和字段，分别核对源限制与教学选择；局部恢复关系继承完整恢复单元，从源到表示检查遗漏、从表示回源检查新增判断的依据。操作许可与目标结果、恢复动作与相同终值分别核对，不凭一种路径推出唯一入口；局部关系不完整时采用忠实文字或完整规则单元。源条件与源初值不自动成为另设情境的实际题设；缺判定必需信息时明示教学假设或保留依赖结果未知，候选问题也核对许可与成功结果的预设。完整条件判准按各结论的实际且/或依赖求值，另一项未知不撤已知项已决定的结果；仅仍依赖缺项的结论保未知，不把纯必要条件当充分判准。先完整保留同一源单元的并列动作、对象和非字段效果，再列字段终值；按实际适用范围复用，字段清单不替完整操作或恢复。可按目标裁减未选单元，纯字段性质须明示维度。正式发布、安装与客户端状态见验收记录。

唯一公开入口为 **$html-guide-kit:guide**，能力 Read，仅显式调用。默认中文，保留术语原文。

显式调用后，技能实际读取材料，保留来源、条件、例外、冲突与缺口，给出 2–3 套不同的“读者＋使用任务＋理解问题”及推荐理由。你明确选择或修改确认后，它才编排指南；没有答复会保留同一待确认方案。推荐、预选、沉默、超时、无关回复或窗口消失都不是确认，技能不能承诺锁住宿主窗口。

指南深度按材料和任务调整，可描述内容顺序、关系表达、分步演示、条件模拟和教学自检。每项必要交互说明操作、变化、结果、反馈和恢复方式。可靠判准提供理由与误区；缺判准给有边界的参考思路，允许重试，不作能力评分或长期掌握判断。

交付物为聊天中可复制的指南文本。本入口只新建指南，不提供指南修订、已有方案比较或已有 HTML 审查，不制作 HTML、代码或文件，也不提供具体制作工具操作说明。

公开方法保存在 [guide](skills/guide/SKILL.md)、[指南框架](skills/guide/references/guide-framework.md) 和 [交互设计](skills/guide/references/interaction-design.md)，均随包分发，相对实际安装的技能定位，无个人路径或其他项目依赖。
