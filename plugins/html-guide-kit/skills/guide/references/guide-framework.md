# 指南框架

本参考用于目标、保义和编排，非章节模板。完整读后使用；交互见[交互设计](interaction-design.md)。用户明定才以入口/参考作教材，不自选方法主题。

## 1. 读取与证据

阅读报告分宿主入口正文、实际回包及后续补读。命令成功、长度、外层汇总或自述不证全文；截断须补齐或标未读范围，不假参照。遵守用户明定顺序；无法完成报告实际顺序及缺口，不补写理想流程。

已知只读模式、Read 能力或权限设置不证明当次拒读原因。回包仅称拒绝或策略拦截时，只述读取未完成、拒绝事实及原因/权限范围未知，不命名为只读、沙箱、路径、安全等策略。缓存位置、工作目录、缺正文或别文件成功不证禁读，也不保证换客户端能读。仅陈述本次回包明确支持的限制类型、对象、范围或原因。可在已授权入口逐文件/分段补读，不绕过已知权限、不称未尝试已禁止；无法补读索取必要缺失内容。范围拒绝用已知合同，不附未证环境理由。

## 2. 材料与依据

列名称、定位、版本/明确快照、已读范围、支持及缺口。文件用来源身份及章/行，网页用实际页面/章，粘贴标本次快照；不造定位或版本，跨会话仅明确快照、不假定同步。

分清四类内容，逐项归因，不让相邻原文替新增内容背书：

- 原材料：教材对象，保留关键措辞、条件、例外、关系和范围；陈述/提案非已实现或验证。
- 已核验背景：仅实际核验命题及范围；必要时效或影响判断的背景读第一手来源，可读/记忆非核验。
- 教学构造：虚构情境、角色、值或假设就地标身份/范围，非记录、原规则或领域证据。
- 设计判断：组织、交互、新增检查轴及有限推论标理由/边界，不称原文明说或已测效果。

冲突并列保留主张、来源和条件，不选边；仅已取得且适用的明确优先规则可据以使用，仍留原冲突。缺口/未核验只阻相关部分，已有依据继续用，不靠术语、版式或常识补齐。

更新先列保留/替换/历史/冲突待定依据；被替换条款连条件、例外、附注退出当前，不从旧版回填。历史标失效、不参与当前模拟/判准；范围不明先澄清，不默认整份替换或任意保留。

说“未提供”前分已有、线索、缺细节、未确认，不因目标未齐否定已有角色/任务。无可定位教材且无明确主题快照时索取最小材料，不自定主题；后来到达按真实范围重整，不追认自选目标。附加缺口拒绝理由逐项有据。

## 3. 目标与等待

每次新建给 2–3 套不同的读者 Audience、使用任务 Task、理解问题 Understanding Questions。读者列相关情境/责任/明确前置知识，不推人格、智力或能力；任务是具体判断/说明，不仅了解；问题可观察，标材料支持/缺口。差异来自信息、任务或深度，非角色改名；已有目标可作一套，仍等确认。

给取舍、推荐和材料/任务理由，目标推荐非答案提示。选择前仅材料范围/目标/待选，不给章节/交互草稿/成品。明确选定已有方案即足够，不要求特定关键词或第二批准；修改目标须确认采用修改后目标。默认/推荐/预选/沉默/超时/无关含糊回复/窗口消失不算选定，不指目标的直接做/一般授权/工具默认不跳过。歧义只澄清，未答同一方案可重述不自换；仅用户修改或材料实质改变才更新再等。不承诺锁住/保持/恢复宿主；用户停即停。

## 4. 保义

先定原意再表达；术语/中文对照/值型在正文、标签、表格、自检一致，原变量与派生真假分名给推导。短引/忠实转述紧邻定位/条件/限制，摘要/案例/索引非原文全部权威。且/或、可能/保证保义；未说明非没有、可以非必然、本例非所有。

关系按源选表达，不凭版式添结论：分类用有名清单/分类表，不默示步骤/互斥/穷尽；层级用树/嵌套，多归属用表，页面层级不默示领域包含；过程用时间线/步骤/条件分支，留循环/跳过，先后不证因果；状态表/转移分状态与动作，满足非已发生；依赖表/矩阵写谁需什么，不默示运行顺序、不压多对多；因果文字有条件/范围/依据，不凭相关/相邻/参数变化/演示；数值表/图描述留单位/尺度/来源，不以面积夸差/造数。图连接给起终、含义、方向、依据、条件，标签非证据；连接若表达可执行、状态转换或字段结果，须在本图写足源必要当前态、直接操作及全部前提，或实际明示本图继承的完整共同规则；资格条件节点不能独自指向操作成功或结果态。“操作后”不代进入该操作的条件，图的分层、前章规则及章节定位不自动建立本图范围。仅条件关系未附操作或字段结果可单独表达，不增源未设前提；颜色/空间/大小/对齐/图标只辅原义，源/阅读/演示顺序分清。

范围保留原对象和谓词：某事项不在范围，不等于其持有者在其他已覆盖事项也不适用；另选读者子集标设计，不新增源资格。先确定排他结论的对象、谓词与局部范围，再按同一维度核对依据：执行某恢复动作与得到某组终值分开判断，源规定一种恢复方式不证明它是唯一终值入口；其他已覆盖动作或明确标注的教学设置也可能得到相同字段值，同值不证明同动作或触发。每处“只、仅、才、始终、必然”须原文明确支持，或完整局部枚举证明，含影响所述结果的常规动作、恢复、重置及例外；演示只选一种路径不证源排他，不确定完整就不用排他。必要性质比较不等于唯一性断言，按实际命题而非单词判定。就地写范围，引用和远处正确说明不替本处限定。

## 5. 源规则与结果

材料有操作规则时，在首个改写操作结果之前呈现完整源规则单元。按下面顺序逐规则核对，条列或表格均可；这不是指南的固定章节/格式。非操作材料按概念、关系和证据组织，不强造操作目录。

| 核对项 | 逐原规则处理 |
| --- | --- |
| 完整单元 | 记必要当前态、输入、单个直接操作、全部条件/例外、源明定动作/对象/字段结果、局部范围与定位。清除、撤销、恢复也是动作，不能只记终值/初值。对象未定义保留原称呼及缺口，不扩成业务日志、永久删除或外部行为。 |
| 输入与身份 | 区分源明定允许域、源可达值和教材自行选的集合。未设域不造有效性门槛；已命中规则全部前提的输入仍保已知结果。额外限制在起始信息、选项、反馈就地标教学构造/设计、理由和局部范围，不改源覆盖；对象/情境范围条款不自动限定字段取值，不能拿它为教学限制作源依据。 |
| 覆盖与判断 | 固定当前态和单个直接操作，明确实际题问/结果维度，遍查完整适用对象、许可、禁止、排他、恢复及例外。按“仅/其余/不得”匹配，不因状态未专名列出就判未知。分别保允许、禁止、未覆盖；未单列特例、重复、同值、额外意义或提示缺失不撤销已知结果，不添限次/有效性前提。先改态的路径另判，不合并并列或重复操作。 |
| 结果与缺口 | 逐项保全部源明定动作、对象、字段；未述字段不补变化/保持/恢复，条件被读取/判断不证保持。禁止判断不补非法尝试后的字段结果，缺口只限真正未覆盖部分，不抹其他已知结果。新增展示行为按交互设计§2分列设计身份与范围。 |
| 本处表示 | 每个概览、图/表连接、例子、模拟、反馈、恢复、自检及作者项均对应完整单元，含全部前提及结果动作。可实际明示共同规则适用于哪些情境和区域，范围内保义缩写；范围外写足或明确引入完整规则。只给初值、旁表、前例、章节号、后置正确表或“以后须继承”要求，不建立本处范围。无法写足或实际建立本处范围时，先采用完整文字或完整源规则单元，暂不给残缺结果连接；这是可选表达回退，不禁止图或强制格式。 |
| 恢复与新增设计 | 恢复完整保触发条件、原操作、全部清除/撤销/恢复动作、对象、字段与现实边界。局部图要写全，或明确本图完整继承/指向该恢复单元，不能只指初值。新增 UI 触发、动作、结果逐项相邻标设计身份、理由、范围；复用的源恢复结果独立引源，同名操作、相同结果或整页教学标签不替局部归因。源启发只作动机，未知对象不改称、不增减源结果。 |

许可标签、推荐反馈和短句也是操作结论，不把部分资格条件当充分条件。“完成/成功/有效”仅源完整定义、指南已给定义且本处适用时可缩写。源无条件结果不增条件；仅条件真假未附操作许可或字段结果可独立判断。

## 6. 值域与交付

初值、赋值/运算和源可达值不等于全输入域；值型、上下界、整数性、单位、有效性未述则保未知。按§5逐规则区分源限制与教材局部选择：未覆盖部分待补，已覆盖结果继续保留，不把教学输入集合说成材料禁止或材料无规则。

按确认问题找原文再取舍/分组/排序/选表达，删除不改核心结论、比较维度一致。深度看关系/分支/依赖/冲突/例外/目标；短版删冗余装饰不删条件。明确篇幅上限时，先按用户单位给本次全部可见文字预算，含标题/标签/提示/附注；正文目标约上限80%，留核对余量。交付前按相同单位核对全稿，超限压重复不删必要条件/例外/定位，不将超出内容塞附录或后续消息。概览常显结论加细节，条件/例外/来源/比较不藏于主动发现后；交互有收益/代价，静态够就不用，无固定章数/控件/格式/题量。

聊天交付可复制指南，含确认目标、材料范围/限制、必要演示/自检、定位及待补检查。按入口和交互设计§6守文本边界及全篇核对，旁处正确不抵消本处错误；不实际制作、测试、写入或执行。拟检查与已验证分开，设计不证理解改善、稳定掌握或全面可访问性合规。
