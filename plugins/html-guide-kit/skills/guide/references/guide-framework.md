# 指南框架

本参考用于选择理解目标、编排内容和核对文本交付。结构随材料调整；下面是设计判断维度，不是固定章节模板。

## 材料与证据边界

在选择目标前建立够用的材料清单：材料名称、可定位位置、版本或明确快照、实际读取范围、可支持的主张及未覆盖部分。文件来源可以用相对来源身份和章节或行号，网页用可访问的页面与章节，粘贴内容用本次快照说明；不能编造行号、链接、版本或阅读范围。

先区分执行方法与教材对象。技能入口及其参考说明本技能如何工作，不自动成为用户希望讲解的原材料。只有用户明确指定这些方法文档作为教材对象时，才能据此编排相关主题；仅调用技能、列出入口/附件以供遵循流程，并不指定它们为教材材料。缺少用户文档、可定位教材材料或明确主题的对话快照时，先索取最小必要内容，不能自行选通用方法主题或提出依该主题的目标。材料后来到达后按其真实范围重新整理，不追认先前自选主题的方案。

区分四类内容：

| 类别 | 如何使用 | 必须保留的边界 |
| --- | --- | --- |
| 原材料 | 指南讲解的对象；关键措辞、规则和关系回到原文 | 用户陈述或提案并不自动成为已经实现或验证的事实 |
| 已核验背景 | 补足必要定义、背景或条件，标出独立来源及核验范围 | 只对实际核验的命题负责；外部新事实不靠模型记忆冒充核验 |
| 教学构造 | 帮助说明规则或误区的虚构情境、数值或角色 | 清楚标“教学构造”，不充当真实记录、原文规定或领域证据 |
| 设计判断 | 说明为什么某种组织或交互适合本次任务 | 设计理由不等于已测量的理解效果 |

材料含有来源冲突时并列保留主张、来源和适用条件；不能为了给出整齐指南自行选边。只有已取得、适用的明确优先规则才能解释如何使用，并保留原冲突。缺少定义、关系、规则或版本时写出缺口及其影响，不用熟悉术语或版式补完。

必要背景有时效性或实质影响答案时，读取可访问的第一手来源再采用。只核验当前问题所需部分。未能核验时标明“未核验”，可收窄指南到已读材料；若缺口阻断关键判断，保留该部分待补，不把同一缺口泛化为全部内容无法推进。

关键原文可按需要短引或忠实转述，紧邻来源定位、条件和限制。摘要、案例或索引不能继承其指向原文的全部权威。教学整理不能改写原材料事实。

来源明确列出的缺口与为本任务新增的检查轴分别标注。新增读者、任务、比较维度或核验建议属于设计判断或有边界的推论；即使合理，也不能统括为“材料明确指出”。引用与归因逐项对应，不让正确的原文条目替同段新增内容提供来源背书。

来源表、初始值表和引用块逐项核对依据。新增展示字段、页面状态、默认值或反馈文案单列教学构造/设计判断，不继承相邻行或整表的来源。没有初值或反馈规定只能说明原文未规定；教材另设默认时就地标明设计。

材料更新后先建立当前有效依据清单：哪些条款保留、被替换、仅作历史或冲突待定。明确被替换条款的条件、例外、附注一并退出当前事实；新来源没有提供的例外不能从旧条款回填，即使看似兼容或更保守。逐条核对指南引用的版本和有效范围；更新范围不明先澄清，不默认整份替换或任意保留。历史内容若保留须明确失效身份，不参与当前模拟/判准。

声明“材料未提供”前逐字段核对：已有内容、有限线索、未给出的细节与尚未确认分别说明。已有角色或任务线索不能因不足以组成完整目标而被否定；未确认也不等于来源没有提供。保留已有线索后仍给实际不同的目标并等待明确确认。范围拒绝用已确定的边界即可；若附加材料缺口理由，每项同样须有原文依据，不把缺任务或判准扩成读者、任务和判准全部缺失。

## 目标选项

每套选项必须同时说清：

- **读者 Audience**：与材料相关的阅读情境、责任和已明确的前置知识，不推断人格、智力或能力等级。
- **使用任务 Task**：阅读后要做的具体判断或说明，如决定何时适用、追踪依据、解释一个分支；不要只写“了解概念”。
- **理解问题 Understanding Questions**：读者要能回答的可观察问题，指出材料能支持的答案或当前缺口。

2–3 套方案应在关注的信息、判断任务或所需深度上有实际差异。只把同一目标换成“初学者／管理者／专家”三个名字不算差异。可按材料选择“建立概念边界”“判断规则适用条件”“追溯依据与限制”等不同重点，不能机械复用这三个标签。

推荐依据是材料完整度、当前任务及读者需求；说明为什么适合、代价是什么。推荐目标不是推荐知识题答案。所有选项保持可修改，用户选定或修改确认前停留在目标选择阶段。

先按单个操作及确定其结果所需的当前状态组织反馈，再展开其余条件。每个反馈块的标题、表首或紧邻说明必须明确共同前提及其覆盖的全部子分支；若没有这种声明，每个分支自行写足必要状态，不能凭前一行、默认初始面板、旁边的正确表或独立情境默补。条件真假表若给出状态或数值结果，也须有操作及当前状态前提；只有纯条件组合结论时，才可单独讨论组合满足、不满足或未决。

共享互动会更新状态并允许继续或重试时，初始值只约束首步；每次操作取最新状态重新匹配源规则。共同前提范围外先检查其他源规则，已覆盖的结论仍保留，只有未覆盖结果待补；不满足本块前提不自动等于禁止、保持原值或全部未知。逐对代入状态不同但其他条件相同的情形，核对宽分支是否误套或与范围外分支重叠。

若无法把动态反馈的覆盖范围写清，可采用互相独立的固定情境：在该情境处明示必要题设、适用分支、每次尝试如何复位及局部范围，不暗示继承上一情境状态。情境只能补齐标明的教学假设，不能补造源规则；既有源规则不足时仍给有边界参考或待定。设计选择不声称已经实现或测试，不要求固定表格、控件或无关字段。

先整理原材料支持的完整操作规则，再组织呈现：逐项保留操作、必要当前状态与输入、结果字段、条件、例外和来源。每个操作结果断言都须在本处保留完整前提，或明确引用一个就地声明覆盖该处的完整共同规则；这一要求同时适用于概览、标题、常显结论、边界提示、重复操作、演示、反馈、恢复和自检。不能把条件在模拟表写全后，又在概览或重试说明中写成无条件结果；只有纯条件真假判断不附操作结果时，才可单谈组合满足与否。读者不能靠记住旁表、初始面板或上一情境补齐当前前提。压缩篇幅时删冗余，保留限定或明确缩小该结论范围。

恢复与重置逐字段分清原材料规则和教材界面设计。原文规定恢复的字段及其初值仍按原文保留；教材另设的展示状态、提示、反馈、默认值、清除或失效时机须在该条目处标明“本指南的设计判断”及局部范围。混合清单分别标注依据，不能以段末一个源章节把新增界面清理统称材料规定；别处的总标签或设计章节名也不为本处混合归因补证。教材设计只能管理演示与展示，不增加或撤销源操作结果。

## 从问题到内容

确认后，给每个核心理解问题找到必要原文、关系、条件、例外及来源。先确定要保留的意思，再决定标题、分组、阅读顺序和呈现形式。

| 设计判断 | 应明确什么 |
| --- | --- |
| 内容取舍 | 哪些内容是回答问题必需的；哪些只是背景或补充；删除后是否改变结论 |
| 层级与分组 | 标题和组名的依据；内容从属是否与领域中的包含关系区分 |
| 阅读顺序 | 哪些前提先读；读者需要先得到什么结论；顺序是阅读建议还是原材料规则 |
| 同时比较 | 比较维度是否一致；应放在同一状态中查看的内容与限制 |
| 表达形式 | 精确条件适合文字，沿维度比较适合表格，有依据的连接或分支可用图示描述 |
| 交互 | 操作后增加哪种理解、付出什么代价；静态呈现是否已经足够 |

“概览 Overview → 细节 Detail”可以是常显结论加补充说明，不要求加入展开控件。重要条件、例外、来源状态和需要比较的信息不能靠读者主动发现才出现。

复杂度以材料本身判断：关系种类、分支数量、相互依赖、冲突、例外和目标数量。一个清楚的局部规则通常不需要长课程；多来源或多分支材料应展开必要核对。用户要求短版时优先删去冗余和装饰，保留关键边界，不以篇幅为由隐藏条件。

每一条“未规定/待补规则”先固定当前输入和单个操作，再逐条检查原材料是否已有更宽规则覆盖它。源规则不必逐一列出所有特例；已有覆盖不能因为未单列重复、某字段已是结果值、动作看似无意义或没有额外提示而变成缺口。只有原文明确的前提、排除和例外才能改变允许范围。仍符合源条件时给出规则确定的字段结果，即使结果等于当前值；操作的额外意义或展示提示若未规定，单独保留该缺口。若宽规则本身条件不够明确或与适用规则冲突，保留真正缺口，不擅自扩大覆盖。

## 关系与语义忠实 Semantic Fidelity

先确定原文声明了什么，再描述如何表达：

原文术语、中文对照与值类型在所有标签、正文、表格和自检中保持一致。数值、状态等原始变量与由其推导的真假条件分开命名，说明推导依据；不把派生条件当成原术语的新定义。文字压缩、表头或标题不能新增“仅／必须／其他不可”等来源没有的排他量词；原文只描述某情形下的结果时，不扩写为操作仅在该情形可用。

新增排他量词只有两种依据：原文明确支持该局部范围的排他性，或完整枚举该范围全部相关规则后确能证明。枚举包含常规动作、恢复、重置和例外对同一字段的影响；不确定是否完整时沿用非排他的源结论，不能新增“只/仅/其他不可”。每处排他断言就地给范围，标题、关键边界、核对清单和附录同样要求；远处正确提到恢复不能替本处补限定。

范围必须保留原对象与谓词。某物件、规则或事项不在说明范围，不等于其持有者或执行者在其他已覆盖事项上也不适用。不能将对事项的排除改为新读者身份前提或资格条件；若教材另设读者子集，标为设计选择，不归因于原材料。

每处“只／仅／始终／必然”先明确对象和操作范围，再回查全材料的例外、恢复/重置及其他影响同一字段的规则。某段只列部分操作，不支持跨范围的唯一性。若结论仅针对某组业务操作或某段演示序列，在该断言处写明范围，不能依赖远处正确的恢复说明补上限制。

完整输入值域未知不构成禁止具体输入的依据。先检查该固定输入是否已命中某条局部规则及其全部必要前提；已覆盖的输入和结果继续按源判断。未被任何规则覆盖时才保留待补，不自行宣布无效。教材可选择较小的输入集合或禁止某些演示值，但须就地标为本互动的额外设计限制，不能用“材料未给完整范围”冒充源禁止理由。

数值要分开核对初始值、单次赋值或运算结果、源规则内可达的值、完整可接受输入范围及数值类型。某个初值或保持性质的运算不自动定义通用输入值域；原文未声明的上下界、整数性、单位或输入有效性仍是缺口。领域常识不能补作原规则。若教学需要有限输入集合或其他限制，在每个采用该限制的位置标明教学构造或设计判断、所依假设及局部适用范围，不能把它列为原材料的当前事实。别处的构造标签不能给这里未标注的限定追补归因。

| 关系 | 可考虑的表达 | 常见误读 |
| --- | --- | --- |
| 分类／归组 | 有组名的清单或分类表 | 并列项被当成必经步骤、互斥或穷尽分类 |
| 层级／包含 | 标明关系的树或嵌套描述；多重归属可用表 | 页面层级被当成组件包含，未知归属被强塞进树 |
| 时间／过程 | 时间线、步骤或条件分支描述 | 时间先后被当成因果；分支、循环或可跳过条件被删去 |
| 状态／转移 | 状态表或标明触发条件的转换描述 | 条件满足被当成实际动作已发生；状态与一次动作混用 |
| 依赖 | “谁需要什么”的关系表、矩阵或连接描述 | 依赖被当成运行顺序，多对多被压成单向流程 |
| 因果 | 有依据、条件和范围的因果说明 | 相邻、相关、参数变化或演示被当成真实因果证据 |
| 数值 | 有单位、尺度和来源的表格或数据图描述 | 视觉面积或长度暗示未提供的数量或夸大差异 |

图示描述中每条连接都应有起点、终点、含义、方向、依据和适用条件。标签能澄清主张，不能替主张提供证据。“未说明”不等于“没有”，“可以”不等于“必然”，“本例”不等于“所有情况”；“且／或”“可能／保证”等限定保持原意。

重复操作按本次当前状态和源前置条件重新匹配，而不是仅因“再次”就归为未知。符合原允许范围且没有源限次或重复例外时，原结果仍适用；明确赋值的结果碰巧等于原值，也有已知字段结果。将操作可用性、状态/数值结果与额外提示文案分开核对：缺少提示规则不抹掉前两项已知结论，也不为重复操作新增有效性条件。

操作分支表与累计反馈清单分别表达。前者要互斥或明确优先，后者要说明同时合并所有适用项。逐对检查宽泛行和具体行的包含关系，尤其“其他条件任意”；不能因先命中宽泛行而遗漏应保留的已知缺项或未知说明。

将原材料规则、设计阅读顺序和教学演示顺序分别说明。颜色、空间位置、大小、对齐和图标只辅助已有含义，不能偷偷增加职责数量、等级、顺序或关系。

## 指南交付与核对

按任务选用合适内容：已确认目标和材料范围、内容编排、关键原文及边界、表达关系、必要演示和自检、来源定位、待补项与检查方式。它们可以合并成简洁段落，也可按复杂度分节，没有固定章数或必选控件。

指南要让后续读者知道每个设计服务哪个问题；必要交互使用 [交互设计](interaction-design.md) 中的判准与描述方式。描述教材应呈现什么和如何反馈，保持具体制作工具无关，不写实现代码、配置、命令、文件结构或制作与发布操作。

文本交付边界也覆盖拒绝答复和来源引用。原材料包含 HTML 或代码时，以自然语言忠实保留条件与必要语义并给来源定位，不复制代码片段或围栏；解释入口范围时同样不回显被拒请求中的代码。拒绝了制作、审查或写入，并不能抵消实际输出代码的越界。

最终自查覆盖全部核心理解问题：

1. 已确认的读者、任务和问题在指南中一致；没有擅自增加目标。
2. 每个核心结论保留关键原文或忠实转述、来源定位、范围、条件、例外与不保证项。
3. 所有关系及模拟结果有依据；冲突、未知和构造标记保留。
4. 关键内容可见，需要比较的内容可以同时查看。
5. 需要的演示与自检具有操作、变化、结果、反馈和恢复；同一操作的源条件、前置状态及结果在正文、演示、不可用反馈与自检中一致，反例没有误排除允许情形。
6. 深度与篇幅适合材料；交付只含可复制指南文本。

区分拟议检查与已经执行的验证。指南可提出语义、操作及理解任务的检查办法，但当前流程不实际制作或测试教材。设计完整、控件可操作、一次答对或提交完成不证明理解改善、稳定掌握或全面可访问性合规；这些结论需要与对象、任务和范围匹配的额外证据。
