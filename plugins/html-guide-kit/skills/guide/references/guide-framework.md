# 指南框架

用于证据、目标、完整源单元与表达选择；交互计算见[交互设计](interaction-design.md)。以下是内部执行顺序，不是强制展示的章节、表格或控件模板。

## 1. 读取并整理证据

分别记录宿主入口正文、实际回包和后续补读。成功、长度、外层汇总或模型自述不证明全文；截断补齐，否则标未读范围。按用户指定顺序读，不补写理想顺序。逐文件/分段只读，不绕过明确权限拒绝。泛化拒绝只证本次未完成，原因/权限范围未知；只读模式、缓存位置、工作目录、缺正文或别文件成功不证当次禁读，也不保证换客户端能读。仅陈述回包明确支持的限制类型、对象、范围、原因；缺内容索取，范围拒绝只据已知合同。

列材料名称、定位、版本或明确快照、已读范围及支持/缺口。文件定位到章/行，网页到实际页面/章，粘贴标本次快照，不造版本或定位。跨会话仅用明确快照，不假同步。无教材或明确主题快照时索取，不自定主题；方法参考只在用户明定时作教材。

每项内容归为：

- 原材料：保关键措辞、关系、条件、例外和范围；陈述/提案非已实现或已验证。
- 已核验背景：只列实际核验命题及范围；影响判断或时效所需事实读第一手来源，可读/记忆非核验。
- 教学构造：虚构情境、角色、值或假设，就地标身份/范围，不冒充记录、规则或领域证据。
- 设计判断：组织、交互、新增检查轴及有限推论，标理由/边界，不称源明说或已测效果。

相邻原文不替新增内容背书。冲突并列保主张、来源、条件；仅已取得且适用的明确优先规则可用于判断，仍保原冲突。缺口只阻相关部分，不靠术语、版式或惯例补齐。更新区分保留、替换、历史、冲突待定；被替换条款连条件/例外/附注退出当前，不从旧版回填。历史标失效，不参与当前模拟或判准；范围不明先澄清，不默认整份替换或任意保留。

## 2. 先核已知，再提出目标

在材料摘要和每个“未规定”判断前，先固定所问对象、当前态、单个直接操作及结果维度；非操作材料固定相关概念/关系，不强造状态或操作。逐项匹配全部相关许可、禁止、排他、恢复及例外，区分已知、线索、缺细节、未确认。完整宽规则可覆盖未专名列出的状态/输入，仍保其允许或禁止；先改态路径逐步另核。“某状态后续”不当单一缺口：先明确具体操作与维度，只有确实缺失的维度未知，不把已知规则/全组结果说未规定。目标未齐或未确认不等于各角色、任务信息皆缺；附加缺口拒绝理由须逐项有据。

每次新建提出 2–3 套 Audience、Task、Understanding Questions：读者写相关情境/责任/前置知识，不推人格、智力或能力；任务是具体判断/说明，问题可观察并标材料支持/缺口。差异来自信息、任务或深度，不仅换职业名。已有目标可作一套，仍待选择。

给取舍、推荐及材料/任务理由，目标推荐非答案提示。选择前只材料范围/目标/待选，不给章节或成品草稿。明确选定已有方案足够，不要求关键词或第二批准；修改目标须确认采用修改后目标。默认/推荐/预选/沉默/超时/无关含糊回复/窗口消失不算选定，一般授权或不指目标的直接做不跳过。歧义只澄清，未答保同一方案；仅用户修改或材料实质改变才更新再等。不承诺宿主锁定/持续显示/恢复，用户停即停。

## 3. 确认后建立完整源单元

先定原意，再改写。短引或忠实转述紧邻定位、条件及限制；摘要/案例/索引非原文全部权威。术语、中文对照、值型在正文/标签/表/自检一致；原变量与派生真假分名并给推导。且/或、可能/保证不互换；未说明非没有，可以非必然，本例非所有。

操作单元保必要当前态、输入、单个直接操作、全部条件/例外、明确动作/对象/字段结果、适用范围与定位。清除、撤销、恢复也属源动作，不能只记终值。未定义对象保原称呼及缺口，不扩成业务日志、永久删除或外部行为。非操作材料按概念、关系、证据整理，不制造操作目录。

固定当前态及单个直接操作，按实际题问/结果维度匹配全部相关规则，包括“仅/其余/不得”及恢复。分别保允许、禁止、未覆盖。未单列特例、重复、同值、额外意义或提示缺失不撤已知，不添限次/有效性前提。先改态的路径另判，不把并列操作或维度合为待定。禁止判断不补非法尝试后的未述字段；条件被读取/判断不证明字段保持，未述字段不补变化/保持/恢复。

初值、赋值/运算、源可达值、允许域和值型分开，可达性质非全输入域。未述上下界、整数性、单位、有效性保未知，不造域或禁用已命中全部规则前提的输入。教学另选集合/限制在起始信息、选项及反馈就地标构造/设计、理由、范围，不改源覆盖；对象/情境范围不自动限定字段取值。某事项不适用不等于其持有者在其他已覆盖事项也不适用，另选读者子集非新增源资格。

## 4. 选择保义表达

按确认问题找原文，取舍/分组/排序，不改变核心结论，比较维度一致。深度依据关系、分支、依赖、冲突、例外与目标；短版删冗余装饰不删条件。静态够用就不用交互，无固定章数/控件/题量。结论、关键条件/例外/限制/来源及比较不能藏于主动发现之后。

关系表达不添源没有的结论：分类用有名清单/表，不默示步骤、互斥或穷尽；层级用树/嵌套，多归属用表，页面层级不证领域包含；过程留循环/跳过，先后不证因果；状态与动作分开，条件满足非已发生；依赖写谁需什么，不造运行顺序或压多对多；因果留条件/范围/依据，相关、相邻、参数变化或演示不证明因果；数值留单位/尺度/来源，不以面积夸差或造数。颜色、空间、大小、对齐、图标只辅原义；源、阅读、演示顺序分清。

每个图连接给起终、含义、方向、依据和条件。若表达操作许可、转换或字段结果，写足当前态、直接操作、全部前提及源结果，或实际明示本图继承的完整源单元；资格节点不独自指向操作成功/结果态。“操作后”、前章、旁表、章节号及“以后可以引用”不建立本处范围。写不全时先用完整文字/源单元，不给残缺结果连接；不禁止图或强制格式。只谈条件关系、属性比较或必要性质时明确维度，不冒充完整操作结论，也不强加源未设前提。

排他结论先定对象、谓词、局部范围，再核同维度依据。执行恢复动作与得到一组终值不同；一种已命名恢复方式不证唯一终值入口，其他有据动作或明标教学设置可能同值。同值不证同动作、触发或等价。“只/仅/才/始终/必然”须源明说或完整局部枚举，含影响该结果的常规动作、恢复、重置、例外；只演示一条路径不证排他。不确定就不作排他，按实际命题而非关键词审校，远处正确不代本处范围。

## 5. 完整性与交付

概览、例子、图/表、反馈、恢复、自检、附录及作者项都回查对应完整源单元。实际明示共同规则适用的情境和区域，范围内可保义缩写；范围外写足或明确引入完整规则。初值、前例、后置正确表或拟写要求不等于本处范围。恢复保触发、原操作、全部动作/对象/字段及现实边界；新增教学入口的触发和新增UI结果就地标设计身份、理由、范围，源恢复独立引源，不用整页标签或同名操作合成源规范，源启发只作动机。

按[交互设计](interaction-design.md)逐例核算，再全篇双向反查。许可短句、推荐反馈及作者清单也须保义；“完成/成功/有效”仅源完整定义、指南已有定义且本处适用才可缩写。源无条件结果不增条件，纯条件判断不强加业务态。

明确篇幅上限时，按用户单位预算全体可见文字，含标题、标签、提示、附注；正文目标约80%，留核对余量。全稿同单位复核，超限压重复，保必要条件/例外/定位，不塞附录或后续消息规避。聊天交付可复制指南，含确认目标、材料范围/限制、必要演示/自检、定位及待补检查；不实际制作、测试、写入或执行。拟检查与已验证分开，设计不证明效果、稳定掌握或全面可访问性合规。
