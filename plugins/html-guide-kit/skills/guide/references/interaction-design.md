# 交互设计

完整读[指南框架](guide-framework.md)并继承证据、目标选择、源单元及输出边界。本参考处理确认后的演示与反馈核算，不实现或操作教材，不规定固定控件、课时或题量。

## 1. 先定用途与生命周期

每项交互说明理解用途/依据、起始信息/当前态/未知/限制、操作/触发、变化及仍可见条件、结果身份/范围、理由/缺项/定位、改选/重试/回退/复位及旧反馈失效。静态文字、条件表或并列说明足够就用，不为交互而造动作。

先定进入、当前态/输入来源、继续、改条件、重试、退出和复位：共享态首步用明示初值，以后据最新态固定单个操作重匹配，改条件非复位；独立情境每次进入/重试恢复明确题设，标依据/范围，不靠初次面板或暗示继承别情境。未知依赖只阻相关后续，可回明确题设或有据恢复，不把未知操作默作完成/未发生。

同组材料贯穿步骤，每步给当前事实、单个操作/触发、变化、局部结果、限制/来源，保分支、循环、暂停、退出、例外，不强画单线。源需触发时，满足条件/改参数仅更新判断，不自动成为动作发生、成功或业务通过。提交、确认、恢复均标模拟，不外部执行。

可选模式按问题选择：展开保上下文和关键常显，比较可多项同显；切换标当前/范围/返回，比较优先并列不靠记忆；关联高亮有据对应并可取消，不造关联；筛选标条件、隐藏范围及清除，不隐藏关键例外；分步留全局/位置/触发及往返/重置，无依据不造步骤；模拟按源完整性探索输入，不当现实操作或因果验证；自检练习解释与边界，不评能力。

视觉有等价文字，必要信息不只靠颜色、悬停或动画；名称、状态、反馈清楚，考虑键盘、焦点、缩放、窄屏。只列设计及待检查，不称已验证访问或操作。

## 2. 按实际输入逐例核算

先核变量/域、当前态、必要前提、单个直接操作、触发、结果、优先、例外、范围及定位，再决定可判输入：完整覆盖留组合/边界/例外；部分分支保已知，其他标缺项；缺阈值/域/触发者/结果不默认数值或自动动作；冲突无适用优先则并列，不造唯一结果。教学假设单列构造/模型及范围，不充源事实或抹冲突。

每个例子/表行/题目独立按此顺序核对，不从相邻行复制答案：

1. 从本例实际题设读出当前态和每项输入，分已知、否定、未知及局部教学假设。
2. 列本次实际判断的操作和维度，遍查全部相关源许可、禁止、排他、恢复及例外。已给状态可被“其他/其余”等宽规则覆盖，不因未专名列出就判未规定；一态结果不默示他态禁止或保持，别操作前提不套、近名状态不代换。先改态路径另判，不撤已知直接结果。
3. 分开操作许可与分支结果：按源门槛判能否操作，再按全部条件判命中分支及各字段结果。许可不保证获得目标结果；源允许的非目标结果分支不改成不可操作，目标结果条件不追加为操作门槛。“可以操作/可执行”等标签、概览及推荐短句同查全部前提。
4. 逐条计算本例实际缺少的条件和全部适用原因，再生成解释。反查每条理由对应的题设值、源条件、结果是否一致；已满足项不说缺少，未知项不当明确否定。核题干、答案、理由、误区及恢复的同一前提，不能以“应核对”代替实际核对。
5. 逐字段保源明确的变化/保持/动作，未述字段标未述，不补变化/保持/清除/恢复。源明定不可用是已知判断，非法尝试后的未述字段才未知，不能合为全组待定。当前块前提不满足须查其他源规则，不自动全禁/保持/全未知。

纯条件真假不附操作或字段结果时可独立判，不强加当前业务态：且有任一明确否即否，或有任一明确是即是，另一未知不撤该结果；其余未知才待定，全已知按源。未知是缺信息而非新业务值，组合成立非整体可执行/已发生，也不决定其他字段。

输入有效与规则完整分开：源有允许域，越界标超本模拟范围；源未定义域不造域/判无效，已命中全部前提仍保已知。可达性质非全域；另选集合/类型/上下界在起始、选项和反馈就地标构造/设计及范围，旁处标签不补本处。反例不误排源允许情形，不靠惯例裁决冲突或缺口。

## 3. 反馈、重复与恢复

先实际明示共同前提及覆盖分支，范围内可缩写；未建立本处范围则写足当前态/输入/操作，不借前行、旁表、前例、初始面板或拟写要求。反馈包含本例输入、命中规则/缺口、局部结果、理由/误区、限制、来源及恢复，不只列控件名。

重复按最新态及源条件；仍符合且无明定限次/重复例外就沿用源结果，不加值有效或限一次前提。同值赋值仍有源结果/变化量，额外意义或提示缺失不抹已知操作/数值。排他按框架的同谓词/范围核对，不将一种恢复方式说成唯一同终值入口。

分支互斥或有明确优先，累计原因另列并合并全部适用项。逐对查宽行、任意/其他/任一未知等覆盖，不能第一匹配丢已知缺项、未知或累计原因。覆盖难写清可选独立固定情境，明示题设、分支、每次复位及局部假设，不填造规则或删已知结果。

源恢复保触发、原操作、全部清除/撤销/恢复动作、对象、字段及现实边界；不是只列初值。局部表示写全或实际指向完整恢复单元；回退说明返回态和保留/清除，重置列全部恢复/清除对象，不保证现实系统回最后成功态或有同名控件。恢复动作身份和同终值不同义，按实际维度说明。

新增状态、默认、输入保留、选择、高亮、提示、反馈清除/失效与源结果分列，就地标设计身份、理由、范围；源未述不推保持/变化，整页构造标签或进入/重试说明不替本处标签。新增教学入口的触发就地标教学设计，复用源动作/对象/字段/结果独立引源，不合成原规范；同名操作、相同结果不证同触发，源启发是动机而非规范依据。反馈、答案、恢复和作者项均回查。

## 4. 教学自检

只设计教材自检，不在聊天开测验。每题对应确认问题，列判准需要的态/输入/假设/范围及来源，仅相关字段；共享默认实际明示覆盖哪些题及题设覆盖方式，不借题名、面板、前例或别题。源足够才能按明标局部假设判定，不冒充事实或造规则；前提仍缺给条件化参考/待补，不给唯一答案。

可靠判准有适用材料和可核对结果，容纳成立的多答案，不为单选造唯一。反馈给局部判断、理由、误区、定位、限制及改答/重试/重做/回看。缺定义、规则、情境、优先关系或开放取舍时，只给有界参考：假设、成立思路、待核验与不能判断；无假标准答案、自动对错或声称未评自由文本已核验。

不预选或推荐正确答案，目标推荐非答题提示。空/无效答、未提交、沉默、超时、关闭保持待答，不判知识错误。改答清除旧判断或明示失效，新提交按当前答；重做明确选择/反馈清除、题设复位及回材料。题干、判准、理由、误区、重试同一前提，按本题实际值计算，旁处正确不补本题。

可用已核对、已提交等局部状态，不给总分、能力等级、绩效或长期掌握结论。一次答对、操作完成、信心、点击意愿或提示后改答仅证当次事实；反馈后练习不追写此前已掌握。

## 5. 交付前双向反查

遍历全文，含材料摘要、概览、图/表每条结果或恢复连接、示例、模拟、反馈、自检、附录和作者清单：

- 从源到表示：完整单元的必要当前态、直接操作、全部前提/例外及动作/对象/字段是否保全；清除和恢复不可只留初值，不能只检已显示字段有无出处。本处共同范围实际成立才缩写，写不清回完整文字，不给残缺连接。
- 从表示到源：每个许可、否定、未规定、排他、数量及输入限制，依据是否支持同一对象、谓词、维度和范围。未规定先遍相关规则/恢复/其他情形禁止；教学选择不借源范围冒充字段域，缺细节只阻对应部分。
- 从反馈回题设：逐例、逐分支、逐题的输入、答案、实际缺项、理由/误区及恢复一致；必要性质比较不误当完整操作结论，纯条件不加业务态。其他段落正确不抵消本处错误，不按关键词判决。
- 分归因与生命周期：源动作和新增触发/结果相邻分标；共享态、独立题设、重复、返回、旧反馈、重试和恢复一致；完整/缺失规则、可靠/不可靠判准分清。编写要求或章节号不充实际范围，拟检查不写成已验证。

示例、拒绝与引用都用自然语言保义定位，不重印 HTML/代码/伪代码/图形语言/制作命令，不写工具、配置、文件结构或制作发布步骤。可以拟检查新情境解释、遗漏、来源、无效操作及往返查找，未执行标待检查；设计、模拟、自检、静态审查不证明效果、稳定掌握或全面可访问性合规。
