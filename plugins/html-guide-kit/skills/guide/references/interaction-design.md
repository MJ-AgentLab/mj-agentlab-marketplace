# 交互设计

先完整读[指南框架](guide-framework.md)，继承其证据、目标、源基准、谓词/未知边界和表达范围，不另造规则。此处负责确认后的实例、生命周期、反馈、自检，不实现教材或规定展示模板。

## 1. 选必要交互并定生命周期

每项交互服务确认问题，说明用途/依据、起始信息/当前态、未知/限制、单个操作/触发、变化、结果身份/范围、理由/缺项/定位及改选、重试、回退、恢复。静态够用就用，不为互动造动作。

先分共享连续态/独立情境。共享态首步明示初值，以后按最新结果重匹配单操作，改条件不是复位。独立情境进入/重试恢复明示题设、标构造/范围，不继承别题/面板。未知依赖只阻相关后续，可回明确题设/有据恢复，不默作完成或未发生。

说明进入、继续、改条件、暂停、退出、重试、返回、复位及旧反馈失效；各步保事实、动作/触发、局部结果、范围、来源和分支/循环/例外，不强画单线。源需操作/触发时，条件满足/改参数仅更新判断，不证动作、成功或通过。提交、确认、恢复标模拟，不现实执行。

模式按问题选：展开保上下文/关键常显；比较并列同显、不靠记忆；切换标范围/返回。高亮有据且可取消；筛选说明条件/隐藏/清除，不藏例外。分步保全局、位置、触发、往返/重置，不造步骤。模拟依源完整性探索，不作现实/因果验证；自检解释边界、不评能力。

视觉有等价文字，名称/状态/反馈清楚，必要信息不只靠颜色、悬停、动画。键盘、焦点、缩放、窄屏、往返列设计/待检查，不称已验证操作/访问合规。

## 2. 从本例输入逐项计算，不重写源规则

每例、表行、题目引用框架的适用完整源单元，执行以下内部核算，不强制展示表格。

1. 读本例当前态、实际输入、变量/域、触发、假设、范围，分已知、明确否定、未知；原变量/派生真假分开，不复制邻行答案。
2. 固定单个操作、本题维度，按框架遍查完整许可/禁止/排他/恢复/例外；先改态的路径逐步另判。
3. 先判许可，再判全部分支与字段。本处标签/短句也分可执行、通过、获得结果、字段变化；非目标分支不改成不可执行，成功条件不追加为门槛。
4. 逐条计算本例缺项与全部适用原因再写解释。已满足不说缺少，未知不当否定；反查题干、答案、理由、误区、恢复的实际值/源，不用“应该核对”代替核对。
5. 逐字段保明确变化、保持、清除、恢复，未述才未知；读取/判断不证保持。非法尝试许可与未述后果分开，按框架保每项已知后才列剩余缺口。

缺阈值、域、触发者、结果、优先关系不默认数值/自动动作/唯一结果；冲突按框架并列。教学假设标构造/模型和范围，不充事实、不抹冲突。完整规则保组合/边界/例外；部分规则依完整基准保已知，缺项只阻相关部分。

纯条件不强加业务态：AND任一明确否即否，OR任一明确是即是，另一未知不撤结果；其余未知才待定，全已知按源逻辑。未知是缺信息非业务值，组合成立不证整体可执行、动作或字段结果。

输入有效与规则完整分开，按框架保源域/可达值区别。源有域则越界标超范围；未定义域不判无效。另选示例集合/限制，在起始、选项、反馈就地标设计/理由/范围，不误排源允许情形，不靠惯例或旁处标签裁决。

## 3. 分归源结果与教学设计，再组织反馈

每项结果先定身份再编同句/列表/组合触发。源引用只覆完整单元支持的动作/对象/字段；新增状态、默认、输入保留、选择、高亮、提示、反馈清除/失效，逐项标本处设计、理由、范围。同名操作、共同触发、相同终值、统一引用、整页教学标签、进入/重试说明或邻文，不替新增项背书。混合不清可分句/段再引源，不强制格式。

新增教学触发也是设计；复用源动作/结果独立引源，不合成原规范。源启发只作动机、不作新增行为规范；未述不推变化/保持。

恢复复用完整源单元：保原触发/操作、全部清除/撤销/恢复动作、对象、字段、现实边界，不只终值、不换为界面对象。回退写返回态及保留/清除对象、复位列全，不保证现实回最后成功态或有同名控件。同触发清教学选择/反馈仍独立标设计，不能整组引源。

依框架实际声明适用完整单元/本处范围才缩写反馈，否则写足。反馈含本例输入、命中规则/缺口、局部结果、理由/误区、限制、定位、恢复，不只列控件名。

重复按最新态：仍符合且无明定限次/重复例外即沿用源结果，不增值有效/一次前提。同值赋值保源动作/变化量；额外意义/提示/有效性未知不抹已知。排他按框架核同谓词/范围，不把一种恢复当唯一同终值入口。

分支互斥或明确优先，累计原因合并所有适用项。逐对查宽行、任意/其他/未知行重叠，不因第一匹配丢已知、未知、累计缺项。难说明可选独立固定情境，明示事实、分支、复位、假设，不造规则/删已知。

## 4. 教学自检与重试

仅设计教材自检，不聊天开测验。每题对应确认问题，明示相关当前态、输入、动作/触发、假设、范围、源。共享默认实际说明覆盖哪些题/如何被题设覆盖，不借题名/面板/别题。源完整、局部假设明确才确定判定；缺前提给条件化参考/待补，不造规则/事实。

可靠判准有适用材料/可核结果，容纳多答案，不为单选造唯一。反馈给局部结论、理由、误区、定位、限制和改答/重试/重做/回看。缺定义、规则、情境、优先关系或开放取舍，只给有界假设/思路/待核验/不能判断，不造标准答案、自动对错或称未评自由文本已核验。

不预选/推荐正确答案，目标推荐非答题提示。空/无效、未提交、沉默、超时、关闭保持待答，不判知识错。改答清旧判断或标失效，新提交按当前答；重做明确选择/反馈清除、题设复位、回材料。题干/判准/理由/误区/重试同一实际前提，旁处不补本题。

可显示已核对/提交等局部状态，不给总分、能力等级、绩效、长期掌握。答对、操作完成、信心、点击意愿、提示后改答仅证当次，反馈后练习不追此前已掌握。

## 5. 交付前双向反查

依框架执行全篇双向反查，逐条含图表结果/恢复连接，不只查已显示字段。每个许可、否定、未知、排他、数量/输入限制匹配同一对象、谓词、维度、实际范围；不清回完整文字，不给残缺连接。

从反馈反查实际输入、答案、缺项、理由、误区、恢复，分必要性质/纯条件/完整操作；检查本处分归和共享态/独立题设/重复/返回/旧反馈一致。旁处正确不补本处，拟写要求不是实际范围，不按关键词裁决。

完整/缺失规则、可靠/不可靠判准分开；拟检查不当已验证。示例/拒绝/引用仅自然语言保义定位，不重印 HTML、代码、伪代码、图形语言、命令或写工具配置/文件结构/制作发布步骤。可列新情境解释、遗漏、来源、无效操作、往返查找待检查；设计/模拟/自检/静态检查不证效果、稳定掌握或全面可访问合规。
