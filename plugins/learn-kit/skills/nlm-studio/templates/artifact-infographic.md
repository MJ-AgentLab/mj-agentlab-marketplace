# Artifact: infographic

This file is loaded as the `===== MEDIUM CONSTRAINTS =====` section of
`focus_prompt` when `artifact_type=infographic`. Format only.

## Format

- **Layout**: single image, poster-style. Vertical orientation
  preferred (mobile-friendly + print-friendly).
- **Panels**: 5–8 visually distinct panels. Each panel = one
  bite-sized idea.
- **Visual density**: high contrast color blocks + strong
  typography. Numbers and key terms should be large; supporting
  text should be small.

## Panel content by view

- **Foundation view** → 5 panels matching the TL;DR 5-pack. Each
  panel uses everyday-life iconography (cups, doors, traffic
  lights, etc.). Numbers ≤ 7 per panel; prefer icons over digits.
  (See `interaction-overrides.md` — foundation+infographic has an
  explicit visual constraint.)
- **Structural view** → 5–6 panels that visualize the structural
  map — one panel per dimension or layer. Use hierarchy diagrams,
  side-by-side comparisons, dimensional grids.
- **Challenge view** → 5–6 panels each showing one counter-example
  or edge case. Use the "looks-like-X / actually-Y" contrast as
  the panel's visual axis (side-by-side, before-after, expected vs
  actual).

## Headline area

- Top of the poster: topic name (large) + view tier subtitle.
- Optional: one-sentence thesis under the topic name.

## Footer area

- Bottom of the poster: 5-pack TL;DR (foundation), self-check
  list (structural), or final probing question (challenge). One
  line.

## What NOT to do

- No infographic that is just a tall slide deck stacked vertically
  — panels must each have a distinct visual identity.
- No more than 8 panels — at 9+, the visual density collapses and
  panels stop being distinguishable.
- No tiny text — if a panel needs more text than fits at large
  size, split into 2 panels.
- No vendor branding.
- No QR codes / links — this is a self-contained visual.
