# Changelog

## [Unreleased]

### Added

- Introduce Understanding Kit 0.1.0 with the explicitly invoked `pop-quiz` skill, based on the SDLC Understanding Pop Quiz v0.3 design.
- Select necessary knowledge from confirmed responsibilities and critical decisions; apply evidence and quiz-suitability gates.
- Run two base questions plus optional adaptive transfer or post-feedback practice, with explicit second-KU continuation and a hard five-question session limit.
- Keep local understanding signals distinct from stable mastery, preserve high-risk unassessed work, and maintain pending unanswered questions within host capabilities.

Elicit the uncovered task judgment, require a meaningful scenario change and a causal account of both actual selections, and preserve uncertain attribution before feedback.

Version 0.1.0 was the initial development package identity; 0.1.1 is the follow-up correction candidate. No published release or completed desktop acceptance is implied.
