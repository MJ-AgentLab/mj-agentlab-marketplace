# mp-flow-dogfood

运行 npm run check:baseline-tools 和 npm run smoke:codex。冒烟使用隔离 HOME / CODEX_HOME / cache、库和市场镜像，检查 Diagram / Learning Evidence / Explain / HTML 四个开发插件及六技能；独立 8.2.0 公开候选保持原三插件/五技能。普通 prompt 含 arch-diagram、glossary、concept，pop-quiz、learning-record-check 与 guide 三显式入口另查 app-server 元数据和实际调用；开发技能只在仓库作用域发现。候选来源为待测 branch/SHA，公开 v8.1.1 不含新包。实际执行安装缓存的 Python 图表与共用脚本，验证资源归属和无仓库过渡依赖。保存测试隔离库、GitHub 写入使用替身；独立合成角色覆盖诊断、移交保存、有效性与应用两阶段、共享及恢复。按 [新验收账本](../../../docs/runbook/[RUNBOOK]_Learning_Evidence_Kit_Acceptance.md)记录两客户端的安装、调用和实际入口；所有启用提问入口严格待答，原生窗口持续显示须独立证据，文本 pending 或重述不能代替。不可达/失败入口延期，不写通过；结构、发现、模型、窗口、独立批准与 Owner 接受分开登记。

在已有授权范围内由代理执行操作，owner 负责未决事项。需要决定时给出 2–3 个选项、影响及有理由的推荐；必须等待的决定等待答复，推荐不构成批准。详见 [执行与决策规范](../../../docs/rule/[STANDARD]_AI_Engineering_Execution_HITL_Prompt.md)。

Explain Kit 单独/组合安装与解释行为按 [Explain Kit 验收](../../../docs/runbook/[RUNBOOK]_Explain_Kit_Acceptance.md) 执行，Python 必须实际运行；能力限制如实记录，不要求 owner 例行手工操作。

图标变更检查各安装包的 logo/composerIcon 引用和 PNG 内容；四种隔离安装逐包比较源文件与缓存。仓库发现 20 个开发技能，消费者不得发现 mp-design-icon；图标实际视觉与客户端列表/composer 验收另记。

HTML Guide Kit 的新建只读文本和显式确认合同见 [ADR](../../../docs/adr/[ADR]_HTML_Guide_Kit_Addition.md)。验证当前授权集合时，保持旧四种安装并增加HTML单独、与Explain及全部插件；guide和pop-quiz仅显式调用，普通提示仍仅三个自然启用技能。合并后运行修正按插件自身补丁推进，评审/安装/模型/客户端结果分别记录。
