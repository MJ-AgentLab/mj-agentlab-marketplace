# mp-flow-plan

以仓库事实和用户验收标准组织顺序、依赖、文档、测试、风险和回退。市场不维护 plans/；过程计划放在当前任务或 PR 正文。重大决策由 ADR 承载，验收证据由 RUNBOOK 承载。已有实施计划直接细化，不把阶段切换当作重新批准。未决事项给出推荐选项，同时推进独立工作。

在已有授权范围内由代理执行操作，owner 负责未决事项。需要决定时给出 2–3 个选项、影响及有理由的推荐；必须等待的决定等待答复，推荐不构成批准。详见 [执行与决策规范](../../../docs/rule/[STANDARD]_AI_Engineering_Execution_HITL_Prompt.md)。
