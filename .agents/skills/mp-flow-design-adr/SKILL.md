# mp-flow-design-adr

读取 docs/_templates/TEMPLATE_ADR.md 和受影响的已有 ADR。记录 Context、Decision、Consequences、Alternatives、Implementation、Acceptance、References 和 Decision Log。文档放 docs/adr/，使用文档框架的八字段；新决定通过 supersedes 与历史资料建立替代链，旧正文和版本保持可追溯。已经批准的格式迁移或插件退役直接落地。

在已有授权范围内由代理执行操作，owner 负责未决事项。需要决定时给出 2–3 个选项、影响及有理由的推荐；必须等待的决定等待答复，推荐不构成批准。详见 [执行与决策规范](../../../docs/rule/[STANDARD]_AI_Engineering_Execution_HITL_Prompt.md)。
