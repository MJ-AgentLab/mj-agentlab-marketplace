# mp-flow-self-review

固定对比基准与当前提交，逐项核对用户范围和验收：市场/公开技能/仓库技能、版本、文档与历史、CI/发布、事实追溯与资源定位。检查无凭据、临时文件或无关改动。同步 INDEX、AGENTS.md 和 CHANGELOG 的当前部分，历史正文只改迁移链接。报告两段：可重复的本地验证与 AI 判断；未执行项写明限制。独立批准、required checks 和未决正式发布授权仍须满足。

在已有授权范围内由代理执行操作，owner 负责未决事项。需要决定时给出 2–3 个选项、影响及有理由的推荐；必须等待的决定等待答复，推荐不构成批准。详见 [执行与决策规范](../../../docs/rule/[STANDARD]_AI_Engineering_Execution_HITL_Prompt.md)。
