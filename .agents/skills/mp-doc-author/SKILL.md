# mp-doc-author

先读[文档框架](../../../docs/rule/[STANDARD]_Documentation_Framework.md)与已有任务 INDEX，按内容用途/维护责任选择 canonical 或 working，type/state 分开。用 docs/_templates 的领域模板或 TASK_INDEX/PLAN/REPORT 模板，新普通文档九字段含 layer；领域公共 working 另填 purpose。需要持续维护时复用 plans/<稳定任务>/ 的一个 INDEX、主 PLAN 与实际结果出现后的主 REPORT，task/tracking 及主文件/正本链接一致；小任务复用 Issue/PR。原意、接受基线、真实决定、实施和验证分别追溯，不每轮新建全文。旧文档实质修订时审定 layer 并适用严格校验，不再使用原项兼容；冻结原件及外部格式按其合同保留。替换/退役先保存原 Git 来源/版本/正文到 archive 及 history-sources，修复链接、记录有限替代范围并更新 docs/INDEX。

在已有授权范围内由代理执行操作，owner 负责未决事项。需要决定时给出 2–3 个选项、影响及有理由的推荐；必须等待的决定等待答复，推荐不构成批准。详见 [执行与决策规范](../../../docs/rule/[STANDARD]_AI_Engineering_Execution_HITL_Prompt.md)。
