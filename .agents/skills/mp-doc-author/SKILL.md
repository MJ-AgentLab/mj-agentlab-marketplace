# mp-doc-author

按 docs/_templates 选择 ADR/GUIDE/RUNBOOK/SPEC/STANDARD 模板；文档放对应 docs 子目录，使用 type/scope/summary/owner/created/updated/state/version 八字段。根命名文件和 SKILL.md 按外部格式处理。资料为历史时保留正文、版本及来源，当前说明引用新的 ADR 和安装路径。替换/退役文档先归档、修复相对链接、记录替代链并同步 docs/INDEX.md。

在已有授权范围内由代理执行操作，owner 负责未决事项。需要决定时给出 2–3 个选项、影响及有理由的推荐；必须等待的决定等待答复，推荐不构成批准。详见 [执行与决策规范](../../../docs/rule/[STANDARD]_AI_Engineering_Execution_HITL_Prompt.md)。
